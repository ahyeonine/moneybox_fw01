# 다국어 번역 대상

지원: **영어(기본) / 중국어(간체·번체) / 일본어**. 제외: eSIM(외부).

## 필수 (고객 노출 전 영역)
헤더·지점선택·지점상세+신청(환율/원화구매/최소·최대·단위/신청하기)·예약자정보(라벨·오류)·최종확인·정책동의(약관·개인정보 전문, 법적 성격)·예약완료·신청내역조회·이메일 템플릿 6종·공통 에러(한도초과·재고소진·조회없음).

## 선택
- 회사소개: 기존 페이지 재사용 — 다국어 유무 `[확인]`
- 약관 전문: 법무 확정 후 번역(프로토타입 더미는 제외)

## 제외
- CEMS/POS 전체(내부 직원용, 한국어)
- eSIM(외부 서비스 위임)

## 참고
통화명·국가명은 언어별 표준 표기, 날짜/시간은 로컬 포맷.
