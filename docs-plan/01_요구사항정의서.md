# 요구사항 정의서 (v1.0)

개발 대상: 통합웹 고객 프론트엔드

## 모델
온라인 무결제 가예약 → 지점 방문·현장 결제·수령. (외화 계좌입금 불가 → 공항수령·온라인결제 없음)

- **신원확인**: 수령 시 지점 신분증 대조(OCR) = 기존 POS 흐름. 온라인 신분증 수집·본인인증·회원/로그인 없음. 이메일 OTP는 "수신 가능 여부" 확인용
- **환율**: 예약 시 픽스, 회원/비회원 구분 없이 전 고객 동일
- **노쇼**: 이메일 기준 자동취소 누적 N회 시 신규예약 차단 (N `[결정 필요]`)
- **CEMS**: 지점 시재조회 등 (상세 05)

## 범위
- In: 지점수령 예약 · 신청내역조회(이름+이메일) · eSIM 연동 · 회사소개 · 다국어 · 알림/리마인더 · CEMS 연동
- Out: 공항수령 · 온라인 결제 · 온라인 신분증 수집 · 로그인/회원 · 온라인 본인인증

## 핵심 기능
1. **예약 생성**(상세 03): 지점→통화→금액→수령일(리드타임~14일)→예약자정보(이름·이메일+OTP)→최종확인(환율 픽스)→동의→완료. 예약자명=여권 영문명(방문자 명의 동일성 불요구)
2. **조회/변경/취소**: 이름+이메일 조회. 변경 시 재고 재확인. 취소 컷오프 `[결정 필요]`
3. **알림**(이메일): 예약완료 / 수령 전일(방문·취소 원터치 응답) / 자동취소 / 취소. 수령기한 = 수령일 당일 KST 자정, 무응답 시 자동취소
4. **지점 처리**: 예약번호 조회 → 신분증 OCR(기존 POS) → 거래완료
5. **환율 노출**: 지점 로드환율, 전 고객 동일
6. **eSIM**: 외부 연동 / **회사소개**: 신뢰성 고지

## 다국어
영(기본)·중(간/번)·일. eSIM 제외 전체. 약관·개인정보·노쇼 안내 포함.
