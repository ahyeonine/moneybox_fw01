# 해외환전예약 서비스 요구사항 정의서

버전 v1.0 (정책회의 최종본 기준) · 개발 대상: 통합웹(고객용 프론트엔드)

---

## 1. 서비스 개요

> 외국인 고객이 온라인으로 환전을 예약(결제 없음)하고, 지정 지점을 방문하여 신분증 확인 후 현장에서 결제·환전 수령하는 서비스

현재 외화를 계좌로 입금받는 수단이 없어 온라인 결제 자체가 불가능하다. 이 때문에 공항수령(100% 결제완결 전제)은 운영하지 않고, **"온라인 무결제 가예약 + 지점 현장 결제·수령"** 단일 모델로 정의한다.

| 원칙 | 내용 |
|---|---|
| 수령 방식 | 지점수령 단일 (공항수령 없음) |
| 결제 구조 | 무결제 예약 + 지점 현장 전액결제 |
| 신원확인 | 지점 현장 OCR (온라인 신분증 업로드 없음) |
| 환율 | 예약 시점 픽스, 회원/비회원 차등 |
| 노쇼 대응 | 제재 있음(패널티) — 이메일 기준 누적 N회 도달 시 신규 예약 차단 (N값 `[결정 필요]`) |
| 어드민(CEMS) | 지점 시재조회 화면만 신규/수정, 본사관리자 신규 없음 (상세: 05_어드민기능정의서) |

---

## 2. 서비스 범위

**In Scope**: 지점수령 예약(다단계) · 비회원 예약조회 · eSIM 연동 · 회사소개 · 다국어(영/중간·번/일) · 알림·리마인더 · CEMS 연동(지점 시재조회만)

**Out of Scope**: 공항수령 · 온라인 결제 · 온라인 신분증 업로드 · 로그인/본인인증 `[결정 필요]`

---

## 3. 사용자 정의

| 유형 | 주요 행위 |
|---|---|
| 고객 (비회원 중심) | 예약 생성/조회/취소, 리마인더 응답 |
| 지점 운영자 | 예약 조회(시재 준비), 신분증 대조, POS 처리 |
| 본사 운영자 | 이번 프로젝트 대상 아님 (기존 CEMS 그대로) |

## 4. 핵심 기능 요구사항

### 4.1 예약 생성 (8단계, 상세는 03_예약플로우_화면정의서)
지점선택 → 통화선택 → 금액입력(최소금액 검증) → 수령일선택(리드타임 반영, 최대 14일(2주)) → 예약자정보(예약자명·이메일) → 최종확인(환율 픽스) → 노쇼 안내동의 → 완료(예약번호 발급)

> 예약자명과 현장 방문자 명의 동일성은 요구하지 않음

### 4.2 예약 조회/변경/취소/제재
- 비회원 조회: 예약번호 + 연락처 기반
- 취소 자유허용 여부, 취소 컷오프 `[결정 필요]`
- 변경(날짜/지점/통화/금액): 재고 재확인 후 허용
- **노쇼 제재**: 동일 이메일 기준 누적 노쇼 N회 도달 시, 예약자정보 입력 단계에서 해당 이메일로 신규 예약 생성 차단 (N값 `[결정 필요]`)

### 4.3 알림/리마인더
- 채널: 이메일 (단일 채널)
- 시점: 예약완료 직후 / 수령 전일(원터치 방문예정·취소 응답) / 자동취소 발생 시 / 취소 처리 시 (※ "수령 당일 무응답 리마인더"는 제거됨)
- **수령기한 = 수령예정일 당일, 한국시간(KST) 자정 기준.** 고객의 현지 시간대와 무관하게 한국시간으로 날짜가 넘어가면 무응답 예약은 자동취소

### 4.4 지점 방문 처리
예약번호 조회 → 신분증 OCR 대조(명의 불일치여도 진행) → POS 처리 → 거래완료

### 4.5 환율 노출
지점별 로드환율 공개, 회원/비회원 차등 (우대율 산정기준 `[결정 필요]`)

### 4.6 eSIM / 4.7 회사소개
eSIM: 기존 페이지 연동, 영문 우선 노출, 연동방식(임베드/리다이렉트) `[결정 필요]`
회사소개: 신뢰성 고지(공식 환전업체, 국내 1위 사업자 등)

### 4.8 로그인/본인인증
연동 가능 여부 `[결정 필요]` → 1차 오픈 포함 여부 결정
