# 다국어 번역 대상 리스트 — 해외환전예약 서비스

지원 언어: **영어(기본) / 중국어(간체·번체) / 일본어** (회의록 [6] 확정)
제외: eSIM 페이지 (외부 연동, 번역 대상 아님)

## 1. 필수 번역 대상 (고객이 반드시 보는 영역)

| 화면/영역 | 번역 항목 | 우선순위 |
|---|---|---|
| 헤더 | 지점 수령/공항 수령/eSIM/회사 소개·문의, 언어선택 라벨 | 최우선 |
| 지점선택 | 지점 리스트 안내, 지도 관련 텍스트 | 최우선 |
| 지점상세+신청 | 영업상태, 실시간 환율 라벨, "원화구매", 최소/최대/단위 안내문구, "신청하기" | 최우선 |
| 예약자정보 | 라벨(이름/이메일), 이메일 형식 오류 메시지 | 최우선 |
| 최종확인 | 요약 항목 라벨 전체 | 최우선 |
| 정책동의 | 노쇼안내 전문, 개인정보 동의 전문, 체크박스 라벨 | 최우선 (법적 성격 있어 번역 품질 중요) |
| 예약완료 | 완료 메시지, 예약번호 안내 | 최우선 |
| 예약조회 | 조회 폼, 리스트, 상세, 취소/변경 관련 문구·확인모달 | 최우선 |
| 이메일 템플릿 4종 | 06_알림리마인더 문서의 템플릿 전체 | 최우선 |
| 공통 에러/예외 메시지 | 한도초과, 재고소진, 조회결과없음 등 | 높음 |

## 2. 선택 번역 대상

| 화면 | 비고 |
|---|---|
| 회사소개 | 현재 기존 페이지 재사용 방침 — 기존 페이지에 다국어 버전 있는지 확인 필요 `[확인 필요]` |
| 약관 전문(법무 검토 후) | 프로토타입 더미 텍스트는 번역 제외, 실제 법무 문구 확정 후 번역 진행 |

## 3. 번역 제외
- CEMS(어드민), POS 화면 전체 — 내부 직원용, 한국어만 지원
- eSIM 페이지 — 외부 서비스 연동, 자체 다국어 지원 여부는 해당 서비스에 위임

## 4. 참고
- 통화명, 국가명 등은 언어별 표준 표기 사용 (예: USD → 영어 "US Dollar", 중국어 "美元" 등)
- 날짜/시간 포맷은 언어권별 로컬 포맷 적용 (PRD 1.3 원칙 참고)
- 번역 리소스/외주 확보는 07_트래킹시트의 조직·일정 항목과 연동해서 별도 진행 필요
