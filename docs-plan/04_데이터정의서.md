# 데이터 정의서

## 예약 (Reservation)
| 필드 | 설명 |
|---|---|
| 예약번호(PK) | `RSV-YYYYMMDD-0001`, 유니크 |
| 상태 | 예약 / 완료 / 취소 |
| 리마인더응답 | 미응답 / 방문예정확인 / 취소요청. **확인해도 노쇼 면제 아님** |
| 재고반영여부 | 기본 false → "방문예정확인" 시 true(이때만 시재 차감). 자동취소 시 true였으면 복구 |
| 지점ID / 통화 | FK / 18개 통화 |
| 환전구분 | `매입` 고정(UI 미노출) |
| 예약환율 | "신청하기" 시점 픽스, 불변 |
| 거래금액 | 외화. 최소~건당최대 범위, 단위 자동보정 |
| 원화금액 | 거래금액 × 예약환율(예약 시점, 불변) |
| 실제적용환율 / 최종원화금액 | 베스트레이트: 거래완료 시 max(예약환율, 오늘환율) 적용값 별도 기록 |
| 예약자명 / 이메일 | 여권 영문명 / 형식검증·노쇼차단 대상 |
| 이메일 인증여부 | OTP 성공 시 true(완료 진행 조건), 이메일 재입력 시 false |
| 수령예정일 | 리드타임 이후 ~ 14일 |
| 신청일시 / 처리일시 | 생성 / 거래완료 시각 |
| 취소사유 | AUTO(노쇼) / CUSTOMER / BRANCH. 노쇼 카운트는 AUTO만 |

## 지점 (Branch)
지점ID·지점명·취급통화·리드타임(통화/지점별)·통화별 가용재고(방문예정확인 시 차감).

## 정책값 (전 지점 공통)
- 통화별 **최소금액** `[수치 미정]`
- 통화별 **건당 최대금액**: 원화 기준 일괄입력 → 통화별 자동환산. 하향 조정 시 기존 예약 소급 없음(적용시작일시 이후 신규만)
- 신청금액단위(예: 20 USD), STEP B에 "최소·최대·단위" 표시

## 노쇼 이력 (이메일 기준)
이메일(PK) · 자동취소 누적횟수(AUTO만) · 최근발생일시 · 차단여부(≥N, 목데이터 N=2).
