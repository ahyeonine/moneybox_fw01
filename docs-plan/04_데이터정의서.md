# 데이터 정의서 — 해외환전예약 서비스

## 1. 예약 (Reservation)

| 필드명 | 타입 | 필수 | 설명/검증규칙 |
|---|---|---|---|
| 예약번호 | string (PK) | 필수 | 형식 `RSV-YYYYMMDD-0001`, 유니크. 목데이터는 순차 채번, 실서비스는 추측 불가능한 형식 권장 |
| 상태 | enum | 필수 | `예약` / `완료` / `취소` |
| 리마인더 응답상태 | enum | 필수 | `미응답` / `방문예정확인` / `취소요청` (기본값: 미응답). **`방문예정확인`이어도 노쇼 면제 아님** — 수령기한 경과 시 동일하게 자동취소 |
| 재고반영여부 | boolean | 필수 | 기본 false. "방문예정확인" 시점에 true로 전환, 이때만 예약시재/가용시재 반영. 이후 자동취소 시 이 값이 true였다면 재고 복구, false였다면 복구 불필요 |
| 지점ID | string (FK) | 필수 | 지점 테이블 참조 |
| 통화 | enum | 필수 | 18개 통화 코드 중 하나 |
| 환전구분 | enum | 필수 | `매입` 고정값 (UI 노출 안 함, 내부 저장용) |
| 예약환율 | decimal | 필수 | "신청하기" 클릭 시점에 픽스, 이후 불변 |
| 거래금액 | decimal | 필수 | 외화 기준. 통화별 최소금액 ~ 건당 최대금액(전체 지점 공통) 범위, 신청금액단위 배수로 자동 보정 |
| 원화금액 | decimal | 필수 | 거래금액 × 예약환율로 자동 계산 (예약 시점 값, 이후 불변) |
| 실제적용환율 | decimal | 선택 | **베스트레이트 보장**. POS 거래완료 처리 시점에 확정. 예약환율 vs 그 시점 기준환율 중 고객에게 유리한 값(원화구매이므로 큰 값)을 적용. 예약환율은 그대로 보존하고 이 필드에 별도 기록 |
| 최종원화금액 | decimal | 선택 | 거래금액 × 실제적용환율. 거래완료 시 확정. 예약환율이 여전히 유리하면 원화금액과 동일 |
| 예약자명 | string | 필수 | 여권 영문명. 온라인에서는 생년월일·신분증 정보를 수집하지 않음(수령 시 지점 신분증 대조는 기존 POS 흐름) |
| 이메일 | string | 필수 | 이메일 형식 검증. 노쇼 N회 누적 이메일은 신규 예약 생성 차단 |
| 이메일 인증여부 | boolean | 필수 | OTP 인증 성공 시 true. 예약완료(8단계) 진행하려면 true여야 함. 이메일 재입력 시 false로 초기화(재인증 필요) |
| 수령예정일 | date | 필수 | 리드타임 이후 ~ 최대 14일(2주) 이내 |
| 신청일시 | datetime | 자동 | 예약 생성 시각 |
| 처리일시 | datetime | 선택 | POS 거래완료 처리 시각 |
| 취소사유 | enum | 선택 | `AUTO`(노쇼/자동취소) / `CUSTOMER`(고객 취소) / `BRANCH`(지점·직원 취소). 상태=취소일 때만 유효. 노쇼 누적 카운트는 `AUTO`만 포함 |

## 2. 지점 (Branch)

| 필드명 | 타입 | 필수 | 설명 |
|---|---|---|---|
| 지점ID | string (PK) | 필수 | |
| 지점명 | string | 필수 | |
| 취급통화 리스트 | array | 필수 | 지점별로 다르게 설정 |
| 리드타임 | int (일) | 필수 | 통화/지점별 준비 소요일 |
| 통화별 가용재고 | map<통화, number> | 필수 | "방문예정확인" 시점에만 차감, 자동취소/취소 시 복구 없음(애초 미반영이므로) |

## 3. 통화별 최소 환전금액 (전체 지점 공통)

| 필드명 | 타입 | 필수 | 설명 |
|---|---|---|---|
| 통화 | enum (PK) | 필수 | |
| 최소금액 | decimal | 필수 | 수치 미정(확정 대기) |

## 4. 건당 최대 환전금액 (환율 리스크 상한, 전체 지점 공통)

| 필드명 | 타입 | 필수 | 설명 |
|---|---|---|---|
| 통화 | enum | 필수 | 전체 지점 공통 (지점 구분 없음) |
| 최대금액 | decimal | 필수 | 원화 기준 일괄입력 → 로드환율로 통화별 자동환산, 개별 수정 가능 |
| 적용시작일시 | datetime | 자동 | 하향 조정 시에도 기존 예약엔 소급 적용 안 함 — 이 시각 이후 신규 예약부터 적용 |

## 5. 노쇼 이력 (이메일 기준)

| 필드명 | 타입 | 필수 | 설명 |
|---|---|---|---|
| 이메일 | string (PK) | 필수 | |
| 자동취소 누적횟수 | int | 필수 | "취소" 명시 응답은 카운트 제외, 수령기한 경과 자동취소만 카운트 |
| 최근 발생일시 | datetime | 필수 | |
| 차단여부 | boolean | 필수 | 누적횟수 ≥ N(미정, 목데이터 N=2)일 때 true, 신규 예약 생성 차단 |

## 6. 신청금액 단위/한도 표시 값 (STEP B 참고용)

| 필드명 | 타입 | 설명 |
|---|---|---|
| 신청금액단위 | decimal | 통화별 입력 단위 (예: 20 USD) |
| 표시용 최소/최대 | decimal | STEP B 화면에 "최소 OO · 최대 OO · 단위 OO" 형태로 노출 |
