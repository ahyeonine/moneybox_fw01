## 결정 완료

| 항목 | 내용 |
|---|---|
| 이메일 인증 방식 | OTP(6자리 숫자, 5분 유효, 재발송 쿨다운 30초, 오답 5회 시 재발송 필요) |
| 환전 최대한도 | 없음 → ⚠️ No.15로 재검토 중 |
| 리드타임 | 최대 14일(2주) |
| 예약자=거래자 동일성 | 불필요 |
| 서비스 언어 | 영어(기본)/중국어(간·번체)/일본어 |
| 노쇼 제재 | ⚠️ **있음(패널티 성격)으로 변경** — 애초 회의록 [7] "제재 없음"과 상충, 정책 재확인 필요. **제재 방식 확정: 동일 이메일 기준 누적 노쇼 N회 도달 시 신규 예약 차단.** N값은 아직 미정 (아래 미결정사항 참고) |
| 로그인 | 없음 (미포함 확정) |
| 회사소개 | 신규 아님 — 기존 페이지 영어 번역만 진행 |
| 무응답 예약 처리 | 수령기한(=수령예정일 당일) 전까지는 취소하지 않음 → 당일 경과 시 자동취소. 명시적 "취소" 응답은 즉시 처리 |
| 지점 로드환율 | 노출함 |
| 현장 거래 플로우 | 예약번호 조회 → POS 처리 |
| 최대금액 하향조정 시 처리 | 기존 예약에는 소급 적용 안 함, 신규 예약부터만 새 상한 적용 |
| 동시 예약 충돌 처리 | 예약 생성 시점엔 재고 미반영. **리마인더 "방문예정" 확인 시점에** 재고 경쟁 발생 — 먼저 확정한 쪽 우선, 늦은 쪽은 재고부족 안내 |
| 수령기한 기준 시간대 | 한국시간(KST) 자정 기준. 고객 현지 시간대 무관 |
