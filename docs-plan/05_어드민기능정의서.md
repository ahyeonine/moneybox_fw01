# 어드민(CEMS/POS/이메일) 기능 정의서

최상위 탭: 외국인 웹사이트 / CEMS / POS / 이메일 / 기획문서

| 화면 | 핵심 |
|---|---|
| 이메일 관리(신규 탭) | 템플릿 6종 편집·테스트 발송·Outbox, 지점 지도 포함 (상세 06) |
| 신규예약 리스트(지점) | 시재 준비용 예약 조회 |
| 공통 설정 | 최소금액·신청단위·리드타임 |
| 환율 리스크(건당 최대) | 전 지점 공통 상한, 원화 일괄등록 |
| 기존 환율설정 | "외국인서비스" 행 추가 |
| 본사관리자 | 전 지점 통합 조회(지점 필터·컬럼) |

## 1. 신규예약 리스트 (지점)
- 목적: 방문 예정 통화·금액 파악(외국인 웹은 **매입=원화구매만**). 조회 범위: 본인 지점
- 노출: 예약번호·수령일·예약자명(여권영문명)·이메일·통화·거래금액·예약환율·원화금액·상태
- 기본 필터: **수령일=오늘 + 방문확인만 보기**(CEMS·POS 공통). 무응답은 숨김("전체보기"에서만), 취소건 미노출. 정렬: 신청일시 최신순
- 기존 CEMS 대비: 성명→예약자명 / 생년월일·입금상태·예약금·종류 삭제 / 휴대전화→이메일

### 상세 모달 / 지점취소
- 행 클릭 → 상세 모달. 하단: 확인 + 예약취소(상태=`예약`만)
- **예약취소**(지점·직원): 사유입력 없이 즉시. 상태→취소(사유=BRANCH), 재고 복구(방문예정확인 건 포함). CEMS는 행 유지(상태만 취소), POS 목록에선 제외. **지점 취소 안내 이메일** 발송
- 고객 직접취소(사유=CUSTOMER)와 템플릿·사유 구분

### POS 거래처리
예약번호 조회 → 신분증 OCR 대조(기존 POS 흐름, 명의 불일치 진행) → 거래완료. (예약 서비스가 신분증을 사전 수집하진 않음)

### POS 환전예약 — 내국인/외국인 탭
- **외국인**(기본): 검색 폼(이름/수령일/예약번호 끝4자리, 이메일 검색 없음). 끝4자리는 단독 매칭(겹치면 리스트). 거래내용 확인 모달엔 이메일 미노출
- **내국인**: "기존 환전예약 사이트" 안내만(기존 시스템 처리, 범위 밖)

### 베스트레이트 정산 (거래완료 시)
매입만 지원 → **실제적용환율 = max(예약환율, 오늘환율)**. 예약환율·예약원화 보존, 실제적용환율·최종원화 별도 기록. POS 화면에 예약/오늘/적용/최종 함께 표기.

## 2. 공통 설정
통화별 최소금액 + 건당 최대금액(3장) / 신청단위(예 20 USD, 외국인 웹 전용 자동 올림) / 리드타임(지점·통화별, 최대 14일). 이메일당 1,000 USD 한도는 정책 메모(미구현).

## 3. 환율 리스크 관리 (건당 최대금액)
- 배경: 매입만 지원 → 환율 하락 시 지점이 시세보다 비싸게 매입해 손실 → 건당 상한 필요
- **전 지점 공통** 하드리밋(초과 시 예약 불가). 최소/단위/최대를 토글로 관리
- 일괄 등록: 원화 기준 1개 입력 → 로드환율로 통화별 자동환산(개별 수정 가능)
- ⚠ 관리자 설정 상한도 통화별 **9,999 USD 상당액까지만**. ⚠ 회의록 [3] "제한 없음"과 상충 → 재확인
- 하향 조정 시 기존 예약 소급 없음(신규부터)

### 기존 환율설정 수정
"외국인서비스" 행 추가(통화·로드환율·적용시각, 전 고객 동일). 매각제외=기본 체크+수정불가(매각 미지원), 매입제외=통화별 설정 가능(체크 시 신청 통화목록에서 제외). 환율은 CEMS 변경 시 STEP B 실시간 반영 + 2분 주기 자동 갱신.

## 4. 본사관리자 (전 지점 통합)
전 지점 예약 통합 조회. 필터에 **지점** 추가 + **지점 컬럼**. 상세 모달·지점취소 동작 동일. 입금확인 목적 없음(예약금 미수취).

## 5. 노쇼 제재
자동취소(AUTO) 누적 N회 시 해당 이메일 신규신청 차단(이메일 입력 시 즉시). N `[결정]`(목데이터 2). 고객 직접취소는 카운트 제외.

## 6. 재고 반영·동시성
- 예약완료 시 재고 미반영. **반영·차감 = 리마인더 "방문 예정" 응답 시점**
- 경쟁은 그 시점에 발생 → 선착순, 나머지는 재고 부족 안내
- **방문예정확인 후 미방문**: 수령기한(수령일 당일 KST 자정) 경과 시 무응답과 동일하게 자동취소. 단 확인 시 잡았던 재고는 복구(무응답 자동취소는 복구 대상 아님). 노쇼 카운트는 동일 적용
- 수령기한 판정: KST 자정 기준(고객 현지시간 무관)
