# CEMS 가이드 — 나중에 한 번에 물어볼 것

가이드에 '설명 필요'로 남았거나, 화면을 보고 추론만 해 둔 항목이다.
답을 받으면 가이드에 반영하고 이 목록에서 지운다.

## 1. 환전율 색 표시 기준 (분홍색 칸 · 빨간 줄)

사용자 확인: "적용환율이 기준환율보다 지점에 불리하면 표시된다" (설정 › 환전율관리 분홍색, 머니 24h › 환전율관리 빨간 줄 모두).

**캡처로 추론한 세부 기준**
- 매각(사실때) 적용환율이 기준환율보다 **낮으면** 표시 → 기준보다 싸게 판다
- 매입(파실때) 적용환율이 기준환율보다 **높으면** 표시 → 기준보다 비싸게 사 온다
- 기준환율과 **같으면 표시 안 함**

**맞는 예 (기준환율 1,493.65 캡처, 매각 쪽)**

| 설정 | 적용환율 | 기준과 비교 | 색 |
|---|---|---|---|
| 수동 1,505원 | 1,505.0000 | 높음 | 없음 |
| 자동 100% | 1,493.6500 | 같음 | 없음 |
| 수동 1,500원 | 1,500.0000 | 높음 | 없음 |
| 수동 1,493원 | 1,493.0000 | **낮음** | **분홍** |

설정 › 환전율관리 USD도 같다: 연남동 예약환율 파실때 1,332 > 기준 1,329.80 → 분홍, 로드환율 파실때 1,325 → 없음.

**안 맞는 예: 머니 24h 홍대 무인기 CHF 줄 (빨간 줄)**
- 매각 수동 1,730원 → 기준 1,608.56보다 높음 (지점에 유리)
- 매입 자동 0% → 1,576.88 → 기준보다 낮음 (지점에 유리)
- 위 기준이면 빨간 줄이 아니어야 한다. 비슷하게 기준보다 7.8% 높게 파는 THB(43원 vs 39.90)는 빨갛지 않다.
- 가능성: 무인기는 다른 기준(평균환율, 다른 지점 환율, 상한선 등)으로 비교하거나, 저장 전 값·다른 시점 값 때문일 수 있다.

**물어볼 것**
- 기준환율과 같을 때는 표시 안 하는 게 맞는가?
- 무인기 CHF 줄은 왜 빨간가? 무인기는 비교 기준이 다른가?
- 설정 화면은 칸만, 무인기 화면은 줄 전체가 칠해지는데 의미 차이가 있는가?

## 참고: 무인기 세부 운영
초기화 버튼, 마감 순서, SMS 설정수량, 준비금설정은 묻지 않는다. 다른 분이 만든 무인기 가이드를 참고해 채울 예정이다
(이 세션 네트워크에서 그 사이트가 막혀 있어 내용 붙여넣기나 접속 허용이 필요).

## 받아야 할 캡처
- 머니 24h › 준비금설정 (지난번 파일이 저장되지 않음)
- 환전예약 › 가상계좌입금조회 · 환전율관리 · 기간별 매출조회 · 휴일관리
- 온라인환전 › 수령관리(목록 + 상세 창) · 취소환불관리 · 미수금 조회 · 환전율관리
- 설정 › B2B 매각 요청 · 영업시간 · 기초설정 · 공지사항(목록 + 상세)
- (선택) 평균환율 계산기 **매입** 계산 화면
