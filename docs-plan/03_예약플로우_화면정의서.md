# 예약 플로우 화면 정의서

개념 8단계 → 실제 6스테이지로 병합 구현(BookingFlow): **STEP A**(지점) + **STEP B**(통화·금액·수령일) 이 1~4단계 흡수, 이후 정보(5)·최종확인(6)·동의(7)·완료(8).

| 단계 | 입력/노출 | 검증 |
|---|---|---|
| 1 지점 | 지점 리스트 | 이후 통화·재고 필터 기준 |
| 2 통화 | 지점 취급 통화만 | 최소금액 `[결정]` |
| 3 금액 | 숫자 | 최소 ~ 건당 최대(전 지점 공통, 05) 범위, 단위 자동보정 |
| 4 수령일 | 캘린더 | 리드타임 이후 ~ 14일 이내 |
| 5 정보 | 이름(여권 영문명)·이메일 + **OTP 인증**(6자리·5분, 이메일 수신 확인용) | 이메일 형식, 노쇼 N회 차단, 오답 5회 재발송, 쿨다운 30초. 인증 완료해야 진행 |
| 6 최종확인 | 요약 + **신분증(여권) 지참 안내** | **이 시점 환율 픽스**. 재고 소프트 체크(실제 차감 아님) |
| 7 동의 | 베스트레이트 안내 + 신분증 안내 + **동의 4종**(①이용약관 ②개인정보 수집·이용 ③제3자 제공 ④노쇼 안내) | 전체 동의 필수. 각 항목 전문 열람 |
| 8 완료 | 예약번호 발급 + 알림 발송 | 강화 옵션 `[결정]` |

## 예외
- 금액 미달·선택일 없음 → 에러 / 재고 소진(6) → 마감 안내 후 1단계 재진입
- **재고 경쟁**: 예약 생성 시엔 재고 미차감 → 충돌 없음. 실제 경쟁은 리마인더 "방문 예정" 확정 시점(선착순), 나머지는 재고 부족 안내
- 중도 이탈 → 임시저장 없음 / 취소 컷오프 `[결정]`

## 상태
`예약` → `완료`(현장 거래) / `취소`(고객·자동). 수령기한 = 수령일 당일. 무응답은 기한 전까지 유지(목록 숨김), 경과 시 자동취소, 명시적 취소는 즉시.
