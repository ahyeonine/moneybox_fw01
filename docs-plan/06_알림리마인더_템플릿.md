# 알림/리마인더 시나리오 및 템플릿 — 해외환전예약 서비스

발송 채널: **이메일 단일** (메신저ID 없음)

## 1. 발송 시점 및 트리거

| 시점 | 트리거 | 목적 |
|---|---|---|
| 예약완료 직후 | 예약 생성 성공 | 예약 내용 확인, 예약번호 재고지 |
| 수령 전일 | 배치(스케줄러)로 매일 발송 | 방문 리마인드, 원터치 방문예정/취소 응답 유도 |
| 자동취소 발생 시 | 수령기한 경과 | 취소 사실 고지 |
| 고객이 직접 취소 시 | 신청내역조회에서 취소 처리 | 취소 확인 |

> ※ "수령 당일 무응답 리마인더"는 제거됨. 전일 리마인더에 무응답이어도 수령기한(당일) 경과 시에만 자동취소하고 "자동취소 안내"로 통지한다.

## 2. 무응답 처리 로직 (재확인)
- 전일 리마인더에 무응답이어도 즉시 취소하지 않음
- 수령기한(=수령예정일 당일) 경과 시에만 자동취소
- 명시적 "취소" 응답은 즉시 처리

## 3. 템플릿 (한국어 기준 초안 — 다국어 버전은 08_다국어_번역대상_리스트 참고)

### 3-1. 예약완료 안내
```
제목: [MONEY BOX] 환전 예약이 완료되었습니다 (예약번호: {예약번호})

{예약자명}님, 환전 예약이 완료되었습니다.

- 예약번호: {예약번호}
- 지점: {지점명}
- 통화/금액: {통화} {거래금액}
- 예약환율: {예약환율}
- 원화금액: {원화금액}
- 수령 예정일: {수령예정일}

💱 현재 적용된 환율이 지금 기준 가장 유리한 환율이에요. 혹시 방문하시는 날 환율이 더 좋아졌다면, 그날의 환율로 적용해드립니다.

[지점 위치 지도 이미지: {지점지도}]
{지점주소}

신청내역 조회/취소는 아래 [신청내역조회] 버튼에서 이름·이메일로 확인하실 수 있습니다.
[신청내역조회]  ← 클릭 시 신청내역조회 화면으로 이동(이름+이메일 자동조회, 해당 예약 상세 진입)

⚠ 방문이 어려우실 경우 미리 취소해 주세요. 수령 예정일이 지나도록 방문하지 않으실 경우 예약이 자동 취소되며, 반복될 경우 서비스 이용에 제한이 있을 수 있습니다.
```

### 3-2. 수령 전일 리마인더
```
제목: [MONEY BOX] 내일 환전 수령 예정이에요 (예약번호: {예약번호})

{예약자명}님, 내일({수령예정일}) {지점명}에서 환전 수령 예정입니다.

[지점 위치 지도 이미지: {지점지도}]
{지점주소}

[✅ 방문 예정입니다]   [❌ 취소할게요]

방문이 어려우신데 응답을 안 주셔도 오늘 안에는 취소되지 않습니다.
단, 수령 예정일 당일까지 응답이 없으면 자동으로 취소돼요.
```

### 3-3. 자동취소 안내
```
제목: [MONEY BOX] 예약이 자동 취소되었습니다 (예약번호: {예약번호})

{예약자명}님의 예약이 수령 예정일 경과로 자동 취소되었습니다.
다시 예약하시려면 아래 버튼을 이용해 주세요.

[다시 예약하기]
```

### 3-4. 인증번호 발송 (신규)
```
제목: [MONEY BOX] 이메일 인증번호입니다

인증번호: {6자리코드}
5분 이내에 입력해 주세요.

본인이 요청하지 않았다면 이 메일을 무시하셔도 됩니다.
```

### 3-5. 지점 취소 안내 (신규 — 지점이 사유로 취소한 경우)
```
제목: [MONEY BOX] 예약이 취소되었습니다 (예약번호: {예약번호})

{예약자명}님, 죄송합니다. 아래 사유로 예약이 지점에 의해 취소되었습니다.

- 예약번호: {예약번호}
- 취소 사유: {지점취소사유}

다시 예약하시려면 아래 버튼을 이용해 주세요.
[다시 예약하기]
```
> `{지점취소사유}`는 프로토타입에서 고정 문구 **"지점 사정으로 인해 예약이 취소되었습니다."** 로 치환된다. (사유 입력 UI 없이 즉시 취소)
> 발송 트리거: **POS 거래처리의 "지점 예약 취소"** 또는 **CEMS 외국인 환전예약관리 상세 모달의 "예약취소"** (둘 다 지점·직원 취소, 취소사유=`BRANCH`).

### 3-6. 고객 취소완료 안내 (신규 — 고객이 직접 취소한 경우)
```
제목: [MONEY BOX] 취소가 완료되었습니다 (예약번호: {예약번호})

{예약자명}님의 예약(번호: {예약번호})이 정상적으로 취소되었습니다.
언제든 다시 예약해 주세요.

[다시 예약하기]
```

## 4. 링크 처리
- "방문 예정입니다" / "취소할게요" 버튼: 이메일 내 원터치 링크(로그인 없이 예약번호 기반 토큰으로 처리)
- 프로토타입에서는 실제 이메일 발송 없이, 신청내역조회 화면의 상태값 변경으로 시뮬레이션해도 무방

## 5. 이메일 관리 화면 (CEMS 상단 "이메일" 탭) — 프로토타입 구현
- 위 6종 템플릿(인증번호 발송 / 신청 완료 / 수령 전일 리마인더 / 자동취소 안내 / 지점 취소 안내 / 고객 취소완료)의 **제목·본문을 관리자가 편집**할 수 있다.
- 각 템플릿에 **"테스트 발송"** 기능: 목데이터 예약을 하나 선택하면 실제 값(예약번호/지점/통화/금액/환율/원화/수령일 등)이 치환된 결과를 **미리보기(모달) + 발송 이력(Outbox)** 으로 보여준다. (실제 메일 전송 없음)
- **지점 위치 지도**: "신청 완료"·"수령 전일 리마인더" 메일에는 지점 정적 지도(더미 마커) + 주소 + 전화가 포함된다. 테스트 발송 미리보기에도 동일하게 표시된다.
- 발송 트리거(프로토타입): 인증번호=예약자정보 단계 OTP, 신청완료=예약완료 시, 전일 리마인더=시뮬레이션 바의 기준일 진행, 자동취소=자동취소 실행 시, 지점취소=POS 거래처리의 "지점 예약 취소" 또는 CEMS 외국인 환전예약관리 상세 모달의 "예약취소", 고객취소=신청내역조회 취소.
