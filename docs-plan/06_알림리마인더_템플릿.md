# 알림/리마인더 템플릿

채널: 이메일 단일. 다국어는 08 참고.

## 트리거 (6종)
| 시점 | 트리거 |
|---|---|
| 예약완료 | 예약 생성 성공 |
| 수령 전일 | 배치(매일). 원터치 방문예정/취소 응답 |
| 자동취소 | 수령기한 경과까지 미방문(수령완료 안 됨) |
| 지점취소 | 지점 사정으로 직원이 취소 |
| 고객취소 | 고객이 신청내역조회에서 [예약취소] |

- "수령 당일 무응답 리마인더" 없음. 전일 리마인더 무응답도 수령기한(당일) 경과 시에만 자동취소.
- 무응답은 즉시 취소 안 함, 수령기한 경과 시 자동취소, 명시적 "취소"는 즉시.

## 템플릿 요지 (한국어 초안)
1. **예약완료**: 예약번호·지점·통화/금액·예약환율·원화·수령일 요약 + 베스트레이트 안내 + **🪪 신분증(여권) 지참** + 지점 지도/주소 + [신청내역조회] 버튼 + 노쇼 경고
2. **수령 전일 리마인더**: 내일 수령 안내 + **🪪 신분증(여권) 지참** + 지점 지도/주소 + [방문 예정]/[취소] 버튼
3. **인증번호**: 6자리 코드(5분). 본인인증 아니라 이메일 수신 가능 여부 확인용
4. **자동취소 안내**: 수령기한 경과 자동취소 통지 + [다시 예약]
5. **지점 취소 안내**: 사유={지점취소사유}="지점 사정으로 인해 예약이 취소되었습니다." (POS/CEMS 지점취소, 사유=BRANCH)
6. **고객 취소완료**: 취소 확인 + [다시 예약]

## 이메일 관리 화면 (CEMS "이메일" 탭)
- 6종 템플릿 제목·본문 편집
- **테스트 발송**: 목데이터 예약 선택 → 값 치환 결과를 미리보기(모달)+Outbox 기록(실제 발송 없음)
- 신청완료·전일 리마인더 메일엔 지점 정적 지도+주소+전화 포함
- 트리거: 인증=정보단계 OTP, 신청완료=예약완료, 전일=시뮬레이션 바 기준일, 자동취소=자동취소 실행, 지점취소=POS/CEMS 취소, 고객취소=신청내역조회 취소
