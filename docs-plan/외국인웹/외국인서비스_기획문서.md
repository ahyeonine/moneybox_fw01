# 외국인서비스 기획문서 (웹)

last update: 2026.10.15 · 작성자: @구아연[Elly]

> 외국인(인바운드) 대상 환전예약 웹 서비스의 기획 문서. 규칙 상세는 「외국인서비스 정책(웹)」, 구현 공통 규칙은 「외국인 웹 공통 규칙」, 확정 이력은 「외국인 웹 의사결정 로그」, 어드민 연동은 「외국인 웹 ↔ CEMS 화면 대응 정책」, 미확정은 「외국인서비스 미결사항」, 화면은 프로토타입을 참조.

## 1. 개요
- 서비스: 외국인 방문객이 입국 전/후 온라인으로 환전을 예약하고, 지정 지점에서 현금으로 수령하는 서비스.
- 배경: 통합웹(m-box.com)에서 외국어 선택 시 외국인 전용 페이지로 분기. 인바운드(대만·홍콩·일본 등) 고객의 환전 편의를 디지털화.
- 채널: 본 문서는 외국인 웹 기준. 앱은 별도 「앱 기획문서」에서 관리(선불카드·푸시·카드 탭 등 앱 전용 기능 포함).
- 1차 범위: 환전예약 + 이심(eSIM) 연결 + 다국어. 이후 실물 부가상품·송금 선결제·여행 상품으로 확장(로드맵 §8).

## 2. 타깃 · 진입
- 타깃: 한국을 방문하는 외국인(개인). 여권 보유자.
- 진입 경로: 통합웹에서 외국어(EN·中文·日本語 등) 선택 → 외국인 전용 페이지 자동 이동(별도 기본 언어 개념 없음).
- 지원 언어: 한국어 · 영어 · 중국어(간체·번체) · 일본어. (문구는 외국인 자문 검증)
- 메뉴: 상단 GNB(환전예약 · 무인환전기 위치 · 부가서비스(eSIM) · 회사 소개) + 우측 유틸(예약 조회 · 로그인/마이 · 언어). 지점 지도는 환전예약의 지점 탐색에서 [목록/지도] 전환으로 제공, 무인기는 '무인환전기 위치' 메뉴에서만 안내.

## 3. 핵심 사용자 플로우
- **홈** — 랜딩(히어로·지역 선택) 중심. eSIM 카드 노출(부가서비스 진입). 현재 환율은 홈에 노출하지 않음(금액 화면에서만 참고). 진행 중 예약 안내는 로그인 회원·수령 전일(D-1)에만 "자정까지 방문 확정"으로 노출, 비회원은 리마인더 메일로만 안내. 가입 유도는 텍스트 링크 한 줄.
1. 지점 탐색 — 지점 탐색 화면에서 [목록/지도] 전환·지점명 검색으로 지점 선택. 환전예약에는 무인기 미노출 — 무인기(머니24h)는 상단 메뉴 '무인환전기 위치'에서 위치만 안내(24시간 운영, 예약 없음).
2. 수령일·통화·금액 — 수령 예정일·시각 → 통화(해당 지점 미취급은 선택 불가) → 금액·거래 방향(외화→원화 기본).
3. 예약자 정보(비회원) — 이름(여권 영문)·이메일 + 이메일 인증.
   - 비밀번호만 추가하면 간편가입(선택) → 회원 우대 대상.
   - 입력 이메일이 이미 가입된 계정이면 로그인 유도 + 비밀번호 찾기(미로그인 시 비회원 계속 — 예약 안 막힘).
   - 회원은 이 단계를 건너뜀.
4. 예약 완료 — 예약번호 발급, 확인 이메일 발송(비회원에게는 회원가입 유도 문구 포함). 제출 결과는 성공/확정 실패/결과 불명으로 구분(결과 불명을 실패로 안내하지 않음).
5. 방문 예정 확인(수령 전일) — 예약 시 입력한 시각에 이메일 발송 → '방문 예정'/'취소' 선택(미응답은 수령기한까지 유지).
   - ※ 당일·전일(수령일까지 1일 이하) 예약은 접수 즉시 방문 확정(컨펌) 처리, 전일 방문 예정 확인 메일 생략.
6. 수령 — 수령 예정일에 지점 방문 → 여권 본인 확인 → 현금 수령. 환율은 수령일 지점 환율 적용.

- 예약 조회: 회원=이메일+비밀번호 / 비회원=예약번호+이메일 (로그인 없이).
- 예약 변경: 고객 화면은 '변경' 한 동작이나, 내부적으로 기존 예약 취소 + 신규 예약 생성(새 예약번호). 환율 미고정이라 재픽스 없음. 변경은 수령 2일 전(D-2)까지, 전일(D-1)부터는 방문 확정·취소만.
- 취소: 예약 상태에서 수령기한 전까지 가능, 취소 수수료 없음(예약 시 결제 없음). 수령기한 경과 시 자동 취소(AUTO). **수령기한 = 수령일 당일이 끝나는 자정(익일 00:00).**

## 4. 환율 · 회원 · 한도 (요약)
- 환율 미고정: 예약 시 고정하지 않음 → 수령일 지점 환율 적용. 현재 환율은 참고용 실시간 시세(실제와 다를 수 있음 명시, 금액 화면에서만).
- 회원·비회원 동일 환율, 회원은 수령 시 현장 재량 우대(사전 확정 아님). 비회원 불이익 없음.
- 한도 없음(양수면 자유). 과장·최상급 표현 지양, 특정 업권(은행 등) 미지목.

## 5. 예약 시재 원칙 (핵심)
- 예약 접수는 시재와 무관 — 접수 시 품절 거절 없음. 지점 매뉴얼 '예약 우선' 원칙 준용(시재 부족해도 지점이 조달해 제공).
- 공급 조절은 통화별 수락 여부로 — 지점이 CEMS에서 통화 단위 on/off, 미수락 통화는 접수 자체를 안 받음("해당 지점 미취급").
- 시재 표시: 방문 예정 확인에서 '방문 예정' 응답(컨펌) 후 CEMS Cash Flow에 차감 예정(-) 표시, 실제 차감은 수령(거래완료) 시점. 당일·전일 예약은 접수 즉시 컨펌.
- 채널 분리: 외국인 웹 예약 시재와 통합웹(국내) 예약 시재는 분리 집계(상호 참고만, 자동 합산·차감 없음).

## 6. 시스템 구성 (프로토타입 기준)
| 구성 | 역할 |
|------|------|
| 외국인 웹사이트 | 고객용 — 예약/조회 (통합웹 외국어 분기 진입) |
| CEMS(어드민) | 본사·지점 예약 관리(외국인 환전예약관리) + 통화 수락 on/off + Cash Flow 시재 + 예약 가능 기간 설정 |
| 이메일 | 인증·예약완료·방문확인·취소 안내 (템플릿 관리) |

- 연동: 회원 인증=기존 계정 체계 / 송금=머니박스 레밋 / eSIM=기존 머니박스 eSIM.
- 고객 화면 ↔ CEMS 트리거·필드·반영 시점은 「외국인 웹 ↔ CEMS 화면 대응 정책」 참조.

## 7. 이메일
- 인증번호 / 예약완료(+비회원 회원가입 유도) / 방문 예정 확인(전일, 당일 예약 제외) / 취소 안내(고객·지점·자동).
- 이메일 인증 — 유효시간 3분 · 재전송 최대 5회 · 초과 시 10분 잠금(국내 전화번호 인증 기준 준용). OTP는 수신 가능 여부 확인용(본인인증 용도 아님).
- 웹은 이메일만 사용(앱 푸시 없음).

## 8. 서비스 로드맵
- 1단계(현재): 외국인 환전예약 + 이심 + 다국어
- 2단계: 실물 부가상품(유심·교통카드, 라이선스 불필요) → 송금 인프라 구축 후 선결제·현금 수령
  - 온라인 선결제+현금 수령은 "수취형 송금" → 송금 라이선스(머니박스 레밋) 기반
  - 실물만 무인 수령, 현금 환전은 지점
- 3단계: 숙박(야놀자·여기어때)·쇼핑·투어 연동
- 4단계: 외부 OTA·여행 서비스 API 연동(예: 트립닷컴)
- 5단계(최종): 머니박스 = 통합 여행 플랫폼

## 10. 오픈 이슈 (「외국인서비스 미결사항」 관리)
- M2. 개인정보 보관·파기 / 제3자 제공 / 필수 동의 항목 — 법무 검토 후 대표님 확인
- M3. 노쇼 관련 동의·법적 고지 — 필요 여부 미정
- (참고 — 회의 안건) 해외카드 선결제 인프라(PG·승인율·수수료), 환전 한도 상한(AML·시재) 도입 여부
