# 외국인서비스 정책 (웹)

## 1. 거래 방향
### 1.1 지원 거래
- 외화 현금 ↔ 원화 양방향 환전 지원
  - 외화 → 원화 (매입): 외화 현금을 내고 원화 수령 *(기본)*
  - 원화 → 외화 (매각): 원화를 내고 외화 현금 수령
### 1.2 고객 화면
- 금액 단계에서 거래 방향 선택(토글) 노출 (기본값 외화 → 원화)
- 현재(기준) 환율 단일 표기

## 2. 환율
### 2.1 환율 적용 기준
- 회원·비회원 동일 환율 적용
- 환전 금액에 따른 별도 우대율 미적용
- 수령일 지점 환율 적용
- 별도 고정 스프레드율 미적용
- 프로모션 혜택은 쿠폰 등 별도 수단으로 제공
### 2.2 환율 미고정
- 예약 시점에 환율을 고정하지 않음
- 적용 환율은 수령일(방문일) 지점 환율
- 현재 환율은 예약 중 금액 화면에서만 참고용으로 노출(홈·완료·조회 미노출). 지점 우대가 적용된 실제 환율과 다를 수 있음을 예약 직전 환율 하단·예약 내역에 명시
### 2.3 표현 유의 (과장광고 방지)
- "가장 저렴 / 최저가 보장 / 무조건" 등 단정·최상급 표현 지양
- 비교는 특정 업권(은행 등) 미지목

## 3. 회원 우대 (현장 재량 우대)
- 회원은 수령 시 지점 현장에서 상황(시세·시재 등)에 맞춰 우대 환율 적용
- 예약에 자동 적용되는 고정 우대율 없음 (사전 확정 아님)
- 비회원은 지점 환율 그대로 적용 (불이익 없음)

## 4. 한도
- 최소·최대·신청 단위 한도 없음
- 양수 금액이면 자유롭게 신청

## 5. 예약 및 수령
### 5.1 결제
- 예약 시 결제 없음, 지점 방문 시 현금 결제
### 5.2 수령일
- 별도 준비일수 제한 없음 — 당일 예약 허용(수령일을 오늘로 선택 가능)
- 기본 기간 제한 없음(오늘 이후 자유 선택). 예약 가능 기간(수령일 상한)은 본사에서만 설정(기본 무제한, 필요 시 '오늘부터 최대 N일'), 지점 변경 불가
### 5.3 수령 방법
- 수령 예정일에 예약 지점 방문 후 환전
- 수령 시 여권 지참 필수, 지점에서 여권 본인 확인
- 온라인 신분증 업로드·사전 본인인증 미지원
### 5.4 수령자
- 수령자명과 예약자명이 달라도 수령 가능, 동일 여부 별도 검증 없음
### 5.5 무인환전기(머니24h)
- 지도에 위치 안내용으로만 표시(24시간 운영). 예약·수령은 유인지점에서만 진행
- *(지도 노출 방식·무인기 안내 화면 등 구현은 공통 규칙 참조)*
### 5.6 지점·통화별 예약 수락
- 지점이 통화별로 예약 수락 여부를 선택할 수 있음(예: A지점 USD·JPY만 수락). CEMS에서 통화 단위 on/off 관리
- 예약 수락 = 지점의 공급 책임이므로, 조달이 어려운 통화는 사전에 미수락으로 관리
- *(고객 화면 '해당 지점 미취급' 표기 방식은 공통 규칙 참조)*
### 5.7 예약 건 시재 조달 (예약 우선 원칙)
- 지점 매뉴얼 준용: "예약을 받은 경우에는 시재가 부족하더라도 지점에서 외화를 구해서 고객에게 제공한다"
- 즉, 수락한 예약은 반드시 이행 — 시재가 부족해도 지점이 조달해 제공. **예약 접수는 시재와 무관(품절 거절 없음)**
### 5.8 예약 시재 관리 (채널 분리)
- 외국인 웹 예약 시재와 통합웹(국내) 예약 시재는 합산하지 않고 채널별 분리 집계, 상호 참고만 가능(자동 합산·차감 없음)
- *(용어 '시재' 통일·CEMS Cash Flow 표시·차감 시점은 공통 규칙 참조)*

## 6. 예약 변경 및 취소
### 6.1 변경·취소 가능 상태
- 예약 상태에서만 변경·취소 가능. 완료·취소된 예약은 불가
### 6.2 예약 변경 (고객=변경 / 내부=취소 후 재예약)
- 고객 화면은 '예약 변경' 한 동작(지점·통화·금액·방향·수령일)
- 내부적으로는 기존 예약 취소(사유=변경) + 변경 내용 반영 신규 예약 생성(새 예약번호 발급). 환율 미고정이므로 재픽스 없음
- 변경 가능 구간은 수령 2일 전(D-2)까지. 수령 전일(D-1)부터는 방문 확정·취소만 가능
### 6.3 예약 취소
- 취소 컷오프·수수료 없음. 수령기한(§7.3) 전까지 취소 가능, 경과 후 고객 직접 취소 불가
- *(취소 처리 상태(확인→처리중→완료/결과확인/확정실패)·메일 발송은 공통 규칙 참조)*

## 7. 방문 예정 확인 및 자동 취소
### 7.1 방문 예정 확인
- 수령일 하루 전(D-1), 예약 시 입력한 시간에 방문 예정 확인 안내(이메일) 발송
- '방문 예정' → 예약 유지(컨펌) / '방문 안 함·취소' → 즉시 취소 / 미응답 → 수령기한까지 유지
### 7.2 자동 취소
- 수령기한 경과 시 BOOKED 자동 취소. 방문 예정 응답 후 미방문도 동일. 사유: AUTO
- **수령기한 = 수령일 당일이 끝나는 자정(익일 00:00).** (당일 예약 허용과 일관되도록, '수령일 당일 00:00'이 아니라 '수령일이 끝나는 자정'으로 정의)
### 7.3 당일·전일 예약 즉시 확정 (W-11)
- 예약 접수 시점에 수령일까지 **1일 이하(당일 예약 D-0, 수령 전일 D-1 접수)**인 예약은 전일 방문 예정 확인 사이클을 돌릴 시간이 없으므로, **접수 시점에 방문 의사가 확인된 것으로 보고 예약 즉시 방문 확정(컨펌) 처리**한다
- 이 경우 전일 방문 예정 확인 메일은 생략(§8 "당일 예약은 전일 메일 제외"와 일치). 컨펌이므로 시재 차감 예정이 즉시 등록되며, 취소는 수령기한 전까지 가능
### 7.4 노쇼
- 노쇼에 따른 신규 예약 제한 없음, 관련 안내만 제공

## 8. 이메일
> 웹 이용자의 알림은 모두 이메일로 제공(발송 조건 등 세부는 공통 규칙 참조)
### 8.1 이메일 인증
- 예약·회원가입 시 인증번호 발송. 이메일 수신 가능 여부 확인(이메일 변경 시 재인증). OTP는 본인인증 용도 아님 (신분 확인은 수령 시 지점 여권)
- 인증코드 **유효시간 3분**. **재전송 최대 5회**, 초과 시 **10분 잠금**(이후 재시도 가능). 국내 전화번호 인증 기준 준용. 안내 문구: "인증번호 전송 한도를 초과했습니다. 10분 후 다시 시도해 주세요."
### 8.2 예약 완료 안내
- 예약 완료 후 예약 정보 발송. 비회원에게는 회원가입 유도 문구 포함(회원 미노출)
### 8.3 방문 예정 확인 안내
- 수령일 하루 전 방문 예정 확인 메일(방문 예정/취소 선택). 당일·전일 즉시 확정 건(§7.3)은 제외
### 8.4 취소 안내
- 고객 취소 / 지점 사정 취소 / 수령기한 경과 자동 취소 각각 안내 메일 발송

## 9. 회원
### 9.1 예약
- 회원가입 없이 예약 가능 (비회원 예약 지원)
### 9.2 회원가입
- 선택 가입 — 이름·이메일·비밀번호(이메일 인증 필요, 비밀번호 8자 이상 영문·숫자)
- 혜택: 회원 우대 + 할인 쿠폰·환율 알림·회원 전용 서비스. 마케팅 수신 동의(선택)
### 9.3 예약 중 간편 가입
- 예약자 정보 단계에서 이름·이메일 인증을 이미 마치므로 비밀번호만 추가하면 그 예약과 함께 회원가입(비우면 비회원)
- 가입 시 해당 예약부터 회원 우대 대상. 가입 완료만으로 예약이 자동 확정되지 않음(이어서 [예약하기])
- 입력 이메일이 **이미 가입된 계정**인 경우: "이미 가입된 이메일이에요. 로그인하시겠어요?" 안내 → **로그인 유도**. 비밀번호를 모르면 **비밀번호 찾기(재설정)** 경로 제공. 로그인 성공 시 해당 예약을 회원 예약으로 승계 (로그인하지 않으면 비회원으로 계속 — 예약 자체는 막지 않음)
### 9.4 회원 예약 간소화
- 회원은 예약자 정보 입력 단계를 건너뜀(금액·수령일 입력 후 바로 예약 완료)
### 9.5 비회원 접근
- 비회원도 로그인·회원가입으로 진입 가능. 회원 전용 기능(쿠폰·환율 알림 등)은 로그인 후 이용

## 10. 예약 조회
- 회원: 이메일 + 비밀번호 / 비회원: 예약번호 + 이메일
- 같은 이메일의 신청내역 전체 조회 (※ 프로토타입은 비밀번호 미검증)

## 11. 지원 언어 · 진입
- 지원 언어: 한국어 · 영어 · 중국어(간체) · 중국어(번체) · 일본어
- 통합웹에서 외국어 선택 시 외국인 전용 페이지로 바로 연결 (별도 기본 언어 개념 없음)
