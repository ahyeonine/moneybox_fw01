# 외국인 웹 화면정의서

> MoneyBox · Foreign Web · Screen Definition

화면별 스펙 문서(Screen Definition Sheet). 각 화면의 기본 정보·적용 정책·화면 구성·인터랙션·이벤트 로그·개발 참고를 정의합니다. 진입·랜딩·홈·예약·마이페이지 전 화면을 포함하며, 화면 그림은 웹 화면설계서, 정책은 외국인서비스 정책과 매핑됩니다.

### 화면 구성 (상태별 버튼)
| 상태 | 버튼·표시 |
| --- | --- |
| 여유 (D-2↑) | [예약 변경] [예약 취소] |
| 임박 (수령 전일 D-1) | 안내 + [방문 확정] [예약 취소] (변경 불가) |
| 확정 완료 | 확정 안내 + [예약 취소] |
| 완료/취소 | 버튼 없이 안내만 |

### Description
- 임박 구간엔 변경 대신 방문 확정/취소
- 리마인더 메일 → 이 상세로 진입(상태 변경 일원화)

### 처리 원칙
- 방문 확정 = **시재 차감 예정(컨펌) 등록** · 실제 차감은 수령(거래완료) 시점. 예약 접수·방문 확정은 시재와 무관 — 품절/SOLD_OUT 거절 없음 (§5.7, D-30-16)
- 변경 가능 구간 = 수령 2일 전(D-2)까지 · 수령 전일(D-1)부터는 방문 확정·취소만
- 당일·전일 예약(수령일까지 1일 이하)은 예약 즉시 방문 확정(컨펌) — 전일 방문 예정 확인 메일 생략 (W-11, §7.3)
- 수령기한 = 수령일 당일이 끝나는 자정(익일 00:00). 경과 시 자동 취소(AUTO) (§7.2)
