# 외국인 웹 와이어프레임

MoneyBox · Foreign Service

외국인서비스 와이어프레임 — 전 화면

외국인 환전예약 서비스의 모든 화면(고객 웹사이트 · CEMS 어드민 · POS · 이메일). 왼쪽은 화면 배치, 오른쪽은 알아야 할 사항(라벨). 실제 디자인이 아닌 기획 검토용입니다.

# A. 고객 웹사이트 (외국인 전용)

## A1 홈 (랜딩)

흐름: 통합웹 외국어 선택 → 진입

화면 배치(위에서 아래로):

- 상단바: 좌측 로고 "MONEY BOX", 메뉴 "환전예약 · 무인환전기 위치 · 부가서비스 · 회사 소개", 우측 유틸 "예약 조회 · 로그인 · 언어(EN·中文·日本語·한국어)" (W-15).
- 큰 제목: "A simple way to exchange money in Korea".
- 서브 문구: "가까운 지점 어디서나, 여권만 보여주면 끝 — 환율도 좋아요".
- 셀링 포인트 나열: "가까운 곳 어디서나" · "온라인 선결제 없음" · "40+ 지점·공항".
- 라벨: "어디서 받으실래요?".
- 지역 선택 칩 3개(가로 배열): 서울 / 부산 / 그 외.
- 기본(파란) 큰 버튼: "예약 시작 →".
- 보조 버튼: "예약 조회하기".
- 부가서비스 카드: "한국 여행 eSIM · 요금제 보기" → 부가서비스 eSIM (W-16).

> (메시징) 비교(평균 %) 제거 — 금액/우대율 혼동 우려. 핵심은 가까움·간편·신뢰, 환율은 보조.
> (진입) 통합웹(m-box.com)에서 외국어 선택 시 이 페이지로 자동 이동. 국내 고객은 통합웹.
> (조회) 상단 "예약 조회하기"로 이메일 없이도 예약 확인 가능.
> (카피 주의) "최저가·무조건" 등 과장·최상급 표현 금지. 비교는 특정 업권(은행) 미지목.

## A2 지역 선택

흐름: 홈 → 지역 → 지점

화면 배치(위에서 아래로):

- 상단바: "← 지역 선택".
- 제목: "어느 지역에서 받으실래요?".
- 지역 선택 칩 3개(가로 배열): 서울 / 부산 / 그 외.

> (지역) 서울·부산 + "그 외" (울산·대구·창원·수원 등 비주요 지점 노출).

## A3 지점 선택 (지도)

흐름: 지역 → 지점 → 금액

화면 배치(위에서 아래로):

- 상단바: "← 지점 선택".
- 지역 바꾸기 칩(서울/부산/그 외) — 선택 지역 우선 추천, 변경 가능.
- 2단 구성(좌: 지점 목록 / 우: 지도).
  - 좌측 지점 목록(전체 지점 노출 · 선택 지역/내 위치 주변 우선):
    - 명동점 · 예약 가능
    - 강남점 · 예약 가능
  - 우측 지도: 예약 가능한 지점 핀(파란)만 표시 — 무인기 미노출.

> (추천) 지역·내 위치는 주변 지점을 우선 추천하는 기준 — 전체 지점은 그대로 노출(특정 지역만 보이게 숨기지 않음). 지역은 이 단계에서도 변경 가능.
> (지도) 환전예약에는 무인기 미노출(W-15). 무인기(머니24h)는 상단 메뉴 '무인환전기 위치'(화면설계서 K1)에서 위치만 안내.
> (선택) 지점 핀/목록 클릭 → 바로 금액 단계.

## A4 금액 · 수령일

흐름: 지점 → 금액 → 정보

화면 배치(위에서 아래로):

- 상단바: "← 금액 입력 · 명동점".
- 방향 토글(세그먼트): [외화 → 원화](선택됨) / [원화 → 외화].
- 라벨: "통화 / 금액".
- 입력칸: "USD ▾ | 1,000".
- 안내 문구: "예약 시 환율 미고정 · 수령일 지점 환율 적용".
- 지점별 원화 이득 비교 카드(금액 입력 시 노출, 미입력 시 숨김): "명동점 · 이 지점 기준 · 이만큼 더 받아요".
  - 타 환전 채널 — (막대) — ≈ ₩2,800 더
  - 무인 키오스크 — (막대) — ≈ ₩5,600 더
  - 공항 — (막대) — ≈ ₩11,200 더
- 토글(점선, 파란 글자): "현재 환율 참고로 보기 ▾".
- 라벨: "수령 예정일".
- 입력칸: "2026-09-30 ▾".
- 기본(파란) 큰 버튼: "다음".

> (환율) 예약 시 미고정 — 수령일 지점 환율 적용. 현재 환율(시세) 숫자는 기본 숨김.
> (비교) 금액 입력 시 "타 채널 대비 원화로 얼마 더 받는지"를 이 지점 환율 기준으로 노출(미입력 시 숨김). 지점마다 환율이 달라 금액도 달라짐.
> (현재환율) "현재 환율 참고로 보기"를 눌러야 노출 — 예약 진행 중에만, 최종(완료) 화면엔 미노출.
> (방향/한도) 기본 외화→원화(매입)·토글로 매각. 최소·최대 한도 없음.
> (수령일) 오늘 이후 자유 선택. 본사 상한(최대 N일) 지정 시만 제한.

## A5 예약자 정보 · 간편가입

흐름: 금액 → 정보 → 완료 (회원 건너뜀)

화면 배치(위에서 아래로):

- 상단바: "← 예약자 정보".
- 라벨 "예약자명 (여권 영문)" + 입력칸 "HONG GILDONG".
- 라벨 "이메일" + 입력칸 "you@example.com".
- 인증 행: 입력칸 "인증번호" + 버튼 "인증".
- 회원 혜택 안내 박스: "회원 혜택 · 비밀번호만 설정하면 회원가입 완료" + 입력칸 "비밀번호 (선택)".
- 체크박스 항목(점선): 마케팅 정보 수신 동의 (선택).
- 기본(파란) 큰 버튼: "예약하기 / 회원가입하고 예약하기".

> (간편가입) 이름·이메일 인증을 이미 받으므로 비밀번호만 추가 → 회원가입. 비우면 비회원. 가입 시 해당 예약부터 회원 우대.
> (인증) 이메일 수신 가능 여부 확인용(OTP), 본인인증 아님. 이메일 변경 시 재인증.
> (회원) 로그인 회원은 이 단계 건너뜀.
> (주의) 여권번호 미수집(이름 영문+이메일만). 신분 확인은 수령 시 지점.

## A6 예약 완료 — 비회원 / 회원 분기

흐름: 정보 → 완료

화면 배치(2-up 비교):

- ① 비회원 완료 (상태 태그: Guest)
  - 중앙 제목: "예약이 완료됐어요".
  - 예약번호 배지: "RSV-20260930-0001".
  - 요약 카드: 수령 지점 = 명동점 / 금액 = 1,000 USD / 수령일 = 2026-09-30 / 적용 환율 = 수령일 환율.
  - 가입 유도 박스: "지금 비밀번호만 설정하면 회원가입 · 우대·쿠폰".
  - 파란 버튼: "예약 조회하기".
  - 보조 버튼: "새 예약 하기".
- ② 회원 완료 (상태 태그: Member)
  - 중앙 제목: "OOO님, 예약이 완료됐어요".
  - 예약번호 배지: "RSV-20260930-0002".
  - 요약 카드: 수령 지점 = 강남점 / 금액 = 1,000 USD / 수령일 = 2026-09-30 / 적용 환율 = 수령일 환율.
  - 안내(노트) 박스: "회원 우대 대상 · 수령 시 현장에서 우대 적용".
  - 파란 버튼: "내 예약 관리하기".
  - 보조 버튼: "새 예약 하기".

> (분기) 완료 화면이 비회원 / 회원으로 나뉨. 비회원=예약번호 + 가입 유도, 회원=이름 인사 + "내 예약 관리하기"(자동 로그인 조회로 이동).
> (가입 직후) A5에서 가입한 경우도 회원 화면. 해당 예약부터 회원 우대 대상.
> (환율) 최종 화면엔 환율 수치 없음 — "수령일 환율"만 표기(현재 환율은 예약 중에만 리빙).
> (이메일) 완료 메일 발송. 비회원에게만 {{signupHook}} 회원가입 유도 포함.
> (취소) 수령기한 전 취소 가능, 취소 수수료 없음. 미방문 시 자동 취소.

## A7 예약 조회 — 직접 조회 / 메일 자동 로그인

흐름: 상단 · 내 예약 · 메일 링크

화면 배치(2-up 비교):

- ① 직접 조회 (로그인 폼)
  - 상단바: "← 예약 조회".
  - 세그먼트 토글: [회원](선택됨) / [비회원].
  - 라벨 "회원: 이메일 + 비밀번호" + 입력칸 "you@example.com" + 입력칸 "비밀번호".
  - 라벨 "비회원: 예약번호 + 이메일" + 입력칸 "RSV-... | you@example.com".
  - 기본(파란) 큰 버튼: "조회".
- ② 메일 링크 진입 (회원 자동 로그인)
  - 상단바: "← 내 예약".
  - 로그인 배너(초록): "OOO님으로 로그인되었어요".
  - 라벨: "신청내역 (2)".
  - 목록 항목: "RSV-…0002 · 강남점" [Booked]
  - 목록 항목: "RSV-…0007 · 명동점" [Completed]
  - 안내 문구: "예약을 눌러 상세·변경·취소".

> (2가지) 회원=이메일+비밀번호 / 비회원=예약번호+이메일. 로그인 없이 조회.
> (자동 로그인) 완료 화면·메일의 "내 예약 관리/신청내역 조회" → 회원은 자동 로그인 배너 + 목록, 비회원은 해당 예약 1건 자동 조회.
> (범위) 같은 이메일의 신청내역 전체. 완료 건도 목록 표시(조회는 가능, 변경·취소 불가).
> (프로토타입) 자동 로그인은 이메일 소유(메일 링크) 기반 시뮬레이션 — 서명 토큰 아님. 실서비스는 기존 계정 체계 연동.

## A8 예약 상세 — 시점별 버튼 분기

흐름: 조회 → 예약 선택

화면 배치(3-up 비교):

- ① 수령 여유 (D-2 이상) (상태 태그: Booked)
  - 요약 카드: 지점 = 명동점 / 수령일 = 10.02 / 통화·금액 = USD 1,000 / 적용 환율 = 수령일 환율.
  - 버튼 행: [예약 변경](보조) + [예약 취소](위험).
- ② 수령 전일 (D-1) (상태 태그: D-1)
  - 요약 카드: 지점 = 명동점 / 수령일 = 내일 (09.30) / 통화·금액 = USD 1,000 / 적용 환율 = 수령일 환율.
  - 안내(노트) 박스: "수령이 임박했어요. 방문 예정이면 방문 확정을 눌러주세요.".
  - 버튼 행: [방문 확정](확인/초록) + [예약 취소](위험).
- ③ 방문 확정 완료 (상태 태그: Confirmed)
  - 요약 카드: 지점 = 명동점 / 수령일 = 내일 (09.30) / 통화·금액 = USD 1,000 / 적용 환율 = 수령일 환율.
  - 배너: "방문 예정이 확정됐어요 · 시재 준비".
  - 버튼 행: [예약 취소](위험).

> (시점 분기) 수령일까지 2일 이상=[예약 변경]+[예약 취소], 수령 전일(D-1)=[방문 확정]+[예약 취소](변경 불가), 확정 후=[예약 취소]만.
> (방문 확정) 수령 전일(D-1)에 고객이 직접 확정 → 지점 시재 준비. 미확정·미방문 시 수령기한 경과로 자동 취소.
> (리마인더 연동) 전일 리마인더 메일의 "예약 확인하기" → 예약내역조회로 이동(회원 자동로그인·비회원 예약번호)해 이 상세에서 [방문 확정]/[예약 취소] 선택. 선택·상태 변경은 상세 한 곳에서만.
> (완료 예약) 상태가 Completed/Cancelled이면 버튼 없이 안내만 표시(변경·취소 불가).

## A9 회사 소개 (About)

흐름: 상단 · About us

화면 배치(위에서 아래로):

- 상단바: "← About us".
- 제목: "환전을 넘어, 외국인의 금융 파트너".

흐름: 환전예약 탭

화면 배치(데스크톱 어드민):

- 상단바: "MONEY BOX 환전 관리시스템 (지점)", 우측 "접속 · IP".
- 탭: [환전예약](선택됨) / [설정].
- 좌측 사이드: "환전예약" / 외국인 환전예약관리(선택됨) / 본사관리자 (전 지점).

  - 필터 행: 구분 ▾ / 신청기간 / 수령기간 / 상태 ▾ / [검색].
  - 목록 표:

화면 배치(위에서 아래로):

- 상단바: 좌측 "RSV-20260805-0001", 우측 상태 배지 [Booked].
- 요약 카드:
  - 예약자명 = MEI LIN

  - 지점 / 수령일 = 강남점 / 08.05
  - 통화 / 금액 = JPY 60,000
  - 적용환율 = 수령일 환율(미고정)
  - 방문 확정 = 확정됨
- 버튼 행: [확인] + [예약취소].

> (표시) 예약자명 아래 생년월일 포함. 환율은 미고정이라 "수령일 환율(미고정)". 고객 방문 확정 여부도 표시(시재 준비 참고).
> (취소) 지점 취소 시 상태=취소(사유 지점) + 고객에게 취소 안내 메일.

> (공통) 목록·상세 구조는 지점 화면과 동일 + 지점 컬럼. 생년월일 포함.

## B4 설정 · 예약 가능 기간

흐름: 설정 탭 (본사 전용)

화면 배치(데스크톱 어드민):

- 탭: [환전예약] / [설정](선택됨).
- 좌측 사이드: "설정" / 예약 가능 기간 설정(선택됨).
- 본문:

# C. POS (지점 단말)

## C1 POS 홈

흐름: 지점 단말 첫 화면

화면 배치(위에서 아래로):

- 상단바(중앙): "MONEY BOX POS".
- 큰 타일 2개(가로): SELL — 외화 파실 때 / BUY — 외화 사실 때.
- 타일 3개(가로): MORE — 더보기 / RESERVATION — 환전예약(선택/활성) / ONLINE — 온라인환전.

> (범위) 프로토타입은 "환전예약" 타일만 동작. 나머지 타일은 실제 POS 맥락 표현용(비활성).
> (지점명) 실제 지점명 노출 없이 일반화 텍스트 사용.

## C2 환전예약 목록

흐름: POS 홈 → 환전예약

화면 배치(위에서 아래로):

- 상단바: 좌측 "환전예약", 우측 "홈".
- 세그먼트 토글: [국내예약](선택됨) / [해외예약].
- 제목: "예약 목록 (5)".
- 목록 항목: "RSV-…1001 · 홍길동" · 1,000 USD · [Booked].
- 목록 항목: "RSV-…1002 · 김민준" · 100,000 JPY · [Booked].
- 목록 항목: "RSV-…1005 · 최수아" · 3,000 CNY · [Booked].

> (구분) 국내예약(한글 이름)/해외예약(영문 이름) 토글. 예약 선택 → 거래처리로 이동.
> (필터) 완료(COMPLETED) 예약은 목록에서 제외 — 처리 대상만 표시.
> (고도화) 신분증 스캔 자동 매칭은 제외(우선순위 밀림). 지점 확인 후 고도화 단계.

## C3 거래처리

흐름: 목록 선택 → 거래처리

화면 배치(위에서 아래로):

- 제목: "거래 처리".
- 입력칸: "예약번호로 조회 (RSV-…)".
- 요약 카드:
  - 예약자 = 홍길동 · 1985-05-16
  - 지점 / 수령일 = 명동점 / 07.31
  - 통화 / 금액 = USD 1,000
  - 적용 환율 = 수령일 환율 · 회원 우대(현장)
- 체크 항목(점선, 체크됨): 신분증 대조 완료 (현장 여권 확인).
- 기본(파란) 큰 버튼: "거래 완료".

> (조회) 예약번호로 조회 → 예약 상세·정산 표시. (스캔 없음)
> (정산) 수령일 환율 적용, 회원 우대 대상은 현장 우대(환율 수치 미표시).
> (본인확인) 수령 시 지점에서 여권 육안 확인(온라인 사전 수집 없음). 예약자·수령자 달라도 가능.

# D. 이메일 (관리자)

## D1 이메일 관리 (템플릿 + 발송 이력)

흐름: 관리자 · 이메일

화면 배치(데스크톱 어드민):

- 상단바: "MONEY BOX 이메일 관리".
- 본문:
  - 제목: "이메일 템플릿 관리".
  - 템플릿 선택 필터(탭): [인증번호](선택됨) / 신청 완료 / 전일 리마인더 / 자동취소 / 지점취소 / 고객취소.
  - 라벨 "제목" + 입력칸 "[MONEY BOX] …".
  - 라벨 "본문" + 입력칸(여러 줄) "{{name}}님, … {{signupHook}} …".
  - 버튼 행: [테스트 발송] + [템플릿 저장].
  - 소제목: "발송 이력 (Outbox)".
  - 이력 항목: [신청 완료] mei@… · 발송됨.

> (6종) 인증번호·신청완료·전일 리마인더·자동취소·지점취소·고객취소. 관리자 편집 가능.
> (치환) {{name}}·{{reservationNo}}·{{signupHook}} 등 토큰 치환. {{signupHook}}=비회원에게만 회원가입 유도.
> (시뮬레이션) 실제 발송 없이 Outbox 기록. 신청완료·리마인더 메일엔 지점 지도 포함.

## D2 이메일 시안 — 총 6종

흐름: 고객 발송 메일

시안 1 — 인증번호 발송 (auth)
- 제목: [MONEY BOX] 이메일 인증번호입니다
- 본문:
  - 인증번호: 000000
  - 3분 이내에 입력해 주세요.
  - 본인이 요청하지 않았다면 무시하셔도 됩니다.
- 발송 시점: 예약·회원가입 중 이메일 인증 요청 시

시안 2 — 신청 완료 (applied)
- 제목: [MONEY BOX] 환전 예약이 완료되었습니다 (예약번호: RSV-…)
- 본문:
  - OOO님, 환전 예약이 완료되었습니다.
  - 예약번호 / 지점 / 통화·금액 / 수령 예정일
  - 적용 환율: 수령일 지점 환율(예약 시 미고정)
  - 수령 시 여권 지참 · (지점 위치 지도 포함)
  - CTA 버튼: 신청내역 조회
  - [비회원] 지금 회원가입하면 우대·쿠폰 혜택
- 발송 시점: 예약 완료 직후

시안 3 — 수령 전일 리마인더 (reminder)
- 제목: [MONEY BOX] 내일 환전 수령 예정이에요 (예약번호: RSV-…)
- 본문:
  - 내일 OO점에서 환전 수령 예정입니다.
  - 수령 시 여권 지참 · (지점 지도 포함)
  - CTA 버튼: 예약 확인하기
  - → 예약내역조회로 이동해 [방문 확정]/[예약 취소] 선택
  - 수령 예정일이 지나면(자정 경과) 자동 취소됩니다.
- 발송 시점: 수령 예정일 하루 전

시안 4 — 자동취소 안내 (autoCancel)
- 제목: [MONEY BOX] 예약이 자동 취소되었습니다 (예약번호: RSV-…)
- 본문:
  - 예약이 수령 예정일 경과로 자동 취소되었습니다.
  - 다시 예약하시려면 예약 화면을 이용해 주세요.
- 발송 시점: 수령기한 경과(미방문) 시

시안 5 — 지점 취소 안내 (branchCancel)
- 제목: [MONEY BOX] 예약이 취소되었습니다 (예약번호: RSV-…)
- 본문:
  - 죄송합니다. 예약이 취소되었습니다.
  - 취소 사유: 지점 사정
  - 이용에 불편을 드려 죄송합니다.
- 발송 시점: 지점(직원) 취소 시

시안 6 — 고객 취소완료 (customerCancel)
- 제목: [MONEY BOX] 취소가 완료되었습니다 (예약번호: RSV-…)
- 본문:
  - 예약이 정상적으로 취소되었습니다.
  - 언제든 다시 예약해 주세요.
- 발송 시점: 고객이 직접 취소 시

> (개수) 고객 발송 메일 총 6종. 관리자(이메일 관리)에서 제목·본문 편집 가능.
> (조회 플로우) 메일의 "신청내역 조회"·"예약 확인하기" → 예약 페이지로 이동. 회원=자동 로그인, 비회원=예약번호+이메일로 조회. 신청완료 메일은 회원=목록, 리마인더 메일은 해당 예약 상세로 바로 진입해 [방문 확정]/[예약 취소] 선택. (완료 화면도 회원/비회원 분기)
> (치환) {{name}} · {{reservationNo}} · {{branch}} · {{pickupDate}} 등 토큰. {{signupHook}}=비회원에게만 회원가입 유도.
> (지도) 신청완료·리마인더 메일엔 지점 위치 지도·주소 포함. 환율 수치는 미표기(수령일 환율로 안내).
