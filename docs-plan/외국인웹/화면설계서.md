# 외국인 웹 화면설계서

> MoneyBox · Foreign Web · 각 화면의 와이어프레임 레이아웃과 설명. 화면 코드는 화면정의서(UI-W-####)와 병기. 정책은 「외국인서비스 정책(웹)」과 동일.

> 진입 — 통합웹(m-box.com)에서 외국어 선택 시 외국인 웹으로 자동 이동. 국내 고객은 통합웹. (앱 설치·스플래시 없음 — 웹 접속)
> 네비게이션 — 상단 메뉴(웹 GNB) — 예약 · 예약 조회 · About · 언어. 지점 찾기·무인기 안내는 예약 안으로 통합(별도 위치 메뉴 없음).
> 게스트 — 로그인 없이도 예약 가능(비회원). 마이페이지·쿠폰·환율 알림 등은 회원 기능.
> 정책 연동 — 예약·환율·수령·취소 규칙은 외국인서비스 정책과 동일(환율 미고정·수령일 지점 환율·무결제 예약 등).

---

## 사이트 전체 플로우

진입·랜딩(O1~O4) → 홈(H1) → 예약(R1 지점 찾기 → R2 지점 상세 → R3 금액·수령일 → R4 예약자 정보·간편가입 → R5 완료 → R6 내 예약 상세) / 마이페이지(M1)

> (분기) 회원은 R4(예약자 정보)를 건너뛰어 R3 → R5로 바로 간다.
> (조회) 예약 조회는 상단 "예약 조회하기"로 — 비회원은 예약번호+이메일, 회원은 자동 로그인.
> (당일·전일 예약) 수령일까지 1일 이하 예약은 접수 즉시 방문 확정(컨펌) — 전일 확인 메일 생략.

# 1. 진입 · 랜딩

## O1 · 언어 선택 (UI-W-1100)
흐름: 통합웹 외국어 선택 → 언어 선택

- 로고 MONEY BOX + 태그라인 한 줄
- 언어 선택: 한국어 · 영어 · 중국어(간체·번체) · 일본어 5종
- 파란 버튼 [시작하기]

> (언어) 선택 언어는 사이트 전역 적용, 마이페이지에서 변경. 유입국(대만·홍콩·일본) 고려해 번체·일본어 노출.

## O2 · 랜딩 · 서비스 소개 (UI-W-1200)
흐름: 언어 선택 → 랜딩

- 상단 GNB: 로고 · 예약 · 예약 조회 · 언어
- 히어로: 핵심 메시지 + 파란 버튼 [예약 시작하기]
- 보조 버튼 [예약 조회하기]
- 스크롤 소개 섹션: 가까운 지점 / 무결제 예약 / 회원 혜택

> (메시징) 핵심은 가까움·간편·신뢰, 환율은 보조. "최저가·무조건" 등 과장·최상급 표현 금지.

## O3 · 로그인 · 게스트 (UI-W-1300)
흐름: 랜딩 → 로그인/게스트 → 위치 허용

- 혜택 배너(회원 우대·쿠폰·환율 알림)
- 입력: 이메일 / 비밀번호 + 파란 버튼 [로그인]
- 보조 버튼 [게스트로 계속하기]

> (게스트) 비회원도 예약 가능 — 로그인 강제 아님. 가입은 예약 중 간편가입으로도 전환.
> (경고) 프로토타입은 비밀번호 미검증 — 실서비스는 기존 계정 체계 연동.

## O4 · 위치 허용 (UI-W-1400)
흐름: 로그인/게스트 → 위치 허용 → 홈

- 안내 문구 + 미니맵
- 파란 버튼 [위치 허용] / 보조 [나중에 하기]

> (위치) 브라우저 위치 권한으로 가까운 지점 정렬. 거부해도 지역 선택으로 이용 가능.

# 2. 홈

## H1 · 홈 (UI-W-2000)
흐름: 외국인 웹 진입·재방문 → 홈 (와이어프레임 A1 랜딩 기준)

- 상단 GNB: 로고 · 예약 · 예약 조회 · 언어(EN▾)
- 히어로: 핵심 메시지 + "어디서 받으실래요?" 지역 선택(서울 / 부산 / 그 외) + 파란 버튼 [예약 시작]
- 보조 버튼 [예약 조회하기]
- (로그인 회원·수령 전일 D-1 방문 확정 전만) 히어로 하단 안내: "RSV-… · OO점 · 내일 수령(D-1) — 자정까지 방문 확정" → 내 예약 상세
- (비회원만) 텍스트 링크 한 줄: "로그인 또는 회원가입하고 회원 우대 받기"

> (환율) 현재 환율 홈 미노출 — 환율은 예약 중 금액 화면에서만 참고 노출.
> (진행 중 예약) 상시 노출 안 함. 로그인 회원·D-1 방문 확정 전에만 안내.
> (비회원) 홈에서 예약 상태 확인 불가 → 방문 확정은 리마인더 메일로만.

# 3. 예약

## R1 · 지점 찾기 (UI-W-3100)
흐름: 홈/예약 → 지점 찾기 → 지점 상세

- 상단바 "지점 찾기" + 지역 선택 칩(서울/부산/그 외) — 지역은 추천 기준, 변경 가능
- 검색창 "지점명 검색"
- 지도: 지점(파란)·무인기 머니24h(청록) 마커
- 지점 리스트: 전체 지점 노출 · 선택 지역/내 위치 주변 우선 추천 · "예약 가능" 배지

> (추천) 지역·내 위치는 주변 지점을 우선 추천하는 기준 — 전체 지점은 그대로 노출(특정 지역만 보이게 숨기지 않음). 지역은 지점 단계에서도 변경 가능.
- 무인기 항목: "머니24h · 위치 안내(예약 불가)"

> (무인기) 위치 안내용 — 선택 시 위치 팝업만, 예약 버튼 없음.
> (통화) 지점이 수락한 통화만 이후 단계에서 선택 가능.

## R2 · 지점 상세 (UI-W-3200)
흐름: 지점 찾기 → 지점 상세 → 금액

- 상단바 "← 지점명" + 미니맵
- 정보 요약: 주소 / 영업시간 / 취급 통화
- 보조 버튼 [길찾기] [전화]
- 파란 버튼 [이 지점으로 예약하기]

> (통화) 취급 통화 = 지점 설정 통화만 표시.

## R3 · 금액 · 수령일 (UI-W-3300)
흐름: 지점 상세 → 금액·수령일 → (비회원) 정보 / (회원) 완료

- 상단바 "← 지점명 · 금액"
- 거래 방향 토글 [외화→원화 / 원화→외화] (기본 외화→원화)
- 통화 선택 + 금액 입력(한도 없음, 양수)
- 지점별 이득 비교(예시) — 금액 입력 시 노출
- "현재 환율 참고로 보기" 토글(예약 중에만)
- 수령 예정일 선택(오늘부터 · 본사 상한 내)
- 파란 버튼 [다음]

> (환율) 예약 시 미고정 — 수령일 지점 환율 적용. 현재 환율 숫자는 '참고로 보기'로만, 완료·조회엔 미노출.
> (당일) 수령일을 오늘로 선택 가능(당일 예약).

## R4 · 예약자 정보 · 간편가입 (UI-W-3400)
흐름: 금액 → 예약자 정보 → 완료 (회원은 건너뜀)

- 상단바 "← 예약자 정보"
- 예약자명(여권 영문) 입력
- 이메일 입력 + [인증] 버튼
- 간편가입 박스: "비밀번호만 추가하면 회원가입(선택)" + 비밀번호 입력
- 체크박스 "마케팅 정보 수신(선택)"
- 파란 버튼 [예약하기]

> (가입) 비밀번호 비우면 비회원. 회원 로그인 시 이 화면 건너뜀.
> (여권번호) 수집 안 함 — 신분 확인은 수령 시 지점.
> (이미 가입된 이메일) "로그인하시겠어요?" 안내 → 로그인 유도 + 비밀번호 찾기. 안 하면 비회원으로 계속(예약 안 막힘).

## R5 · 예약 완료 (UI-W-3500)
흐름: 정보(또는 회원 금액) → 완료

### 비회원
- "예약이 완료됐어요" + 예약번호 · 요약
- 가입 유도 문구
- 보조 버튼 [예약 조회하기]

### 회원
- 이름 인사 + 요약 · 우대 안내
- 파란 버튼 [내 예약 관리하기]

> (환율) 완료 화면엔 환율 수치 없음 — "수령일 환율"만.
> (메일) 완료 메일 발송, 이후 수령 전일 리마인더(당일·전일 예약은 제외 — 이미 컨펌).
> (당일·전일) 접수 즉시 방문 확정(컨펌) 상태로 완료.

## R6 · 내 예약 상세 (UI-W-3600)
흐름: 홈 안내 / 마이 내 예약 / 리마인더 메일 → 상세

### 여유 (D-2 이상)
- 예약 요약 + [예약 변경] [예약 취소]

### 수령 전일 (D-1)
- "수령이 임박했어요. 방문 예정이면 방문 확정을 눌러주세요" + [방문 확정] [예약 취소] (변경 불가)

### 확정 완료
- "방문 예정이 확정됐어요" + [예약 취소]

### 완료/취소
- 버튼 없이 상태 안내만

> (시점 분기) D-2 이상=[예약 변경]+[예약 취소], 수령 전일(D-1)=[방문 확정]+[예약 취소](변경 불가), 확정 후=[예약 취소]만.
> (방문 확정) 시재 차감 예정(컨펌) 등록 — 항상 성공, 품절/SOLD_OUT 없음. 실제 차감은 수령 시점.
> (당일·전일 예약) 접수 즉시 컨펌 — 이 화면에선 바로 '확정 완료' 상태.
> (자동취소) 수령기한(수령일 끝나는 자정) 경과 시 자동 취소.

# 4. 마이페이지

## M1 · 마이페이지 (UI-W-4000)
흐름: 상단 메뉴 마이 → 내 예약 / 알림 설정 / 예약 조회

### 회원
- 프로필(우대 배지)
- 메뉴: 내 예약 · 쿠폰·혜택 · 환율 알림 · 언어 · 로그아웃

### 비회원
- 로그인 / 회원가입 유도
- 예약번호 + 이메일 조회
- 언어

> (알림 설정, UI-W-4200) 웹은 이메일만 — 예약 안내 이메일은 항상 발송(끌 수 없음), 마케팅 수신만 선택 토글(회원).
> (경고) 프로토타입은 계정·비밀번호 미검증.
