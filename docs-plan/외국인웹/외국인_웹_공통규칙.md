# 외국인 웹 · 공통 규칙

> 외국인 **웹** 화면 전반에 공통 적용되는 규칙(메뉴 구조, 전체 플로우, Validation, 회원 데이터, 인증 진입, 알림, CEMS 연동, 구현 보조 가정). 사업·서비스 규칙은 「외국인서비스 정책(웹)」, 미확정은 「외국인서비스 미결사항」 참조. 화면 코드: `UI-W-####`.

## 1. 메뉴 구조
- **상단 메뉴(GNB)**: 환전예약 · 무인환전기 위치 · 부가서비스(eSIM) · 회사 소개 / 우측 유틸: 예약 조회 · 로그인(마이) · 언어 (W-15). 로고 클릭 = 홈
- 지점 지도는 **환전예약 플로우의 지점 탐색(UI-W-3100)** 에서 [목록 / 지도] 전환·지점명 검색으로 제공. **환전예약에는 무인기 미노출**(예약 가능한 유인 지점만)
- 무인기(머니24h)는 상단 메뉴 **무인환전기 위치(UI-W-5000)** 에서만 지도·목록으로 안내(위치 안내용, 예약 없음, 24시간 운영)
- 부가서비스(UI-W-6000)는 1차 eSIM. 홈(메인)에도 eSIM 카드 노출(W-16). 회사 소개 = UI-W-7000
- 지점 탐색은 선택 지역·내 위치로 주변 지점을 **우선 추천**하되 **전체 지점을 노출**하며, 지역은 플로우 안에서 변경 가능(특정 지역만 보이게 숨기지 않음)
- 비회원도 마이에서 로그인·회원가입 진입 가능
- 홈은 랜딩(히어로·지역 선택) 중심 — 현재 환율 미노출, 진행 중 예약 안내는 로그인 회원·수령 전일(D-1)에만, eSIM 카드 상시 노출(환전예약 CTA 아래), 비회원 가입 유도는 텍스트 링크 한 줄

## 2. 전체 플로우 (상태 전이)
> 화면 코드: 예약 조회/목록 UI-W-4100 · 지점 탐색 3100 · 지점 상세 3200 · 금액·수령일·통화 3300 · 예약자 정보/간편가입 3400 · 완료 3500 · 내 예약 상세(취소 포함) 3600

### 2.1 예약
예약 조회/목록 → [새 예약] → 지점 탐색 [목록 ⇄ 지도 · 지점명 검색]
→ 지점 상세 → 수령일·시각 → 통화(해당 지점 미취급 = 선택 불가) → 금액
→ (회원) 신청정보 확인
→ (비회원) 예약자 정보 → 이메일 인증 → 간편가입(선택) → 신청정보 확인
→ [예약하기] → 완료 / 결과 확인중 · 기존 성공 복구 · 재시도 · 확정 실패

### 2.2 예약 제출 실패
제출 → 처리중 ─ 성공 → 완료
            ─ 응답 없음 → 결과 확인중 ─ 생성됨 → 기존 성공 복구 → 예약 상세
            │                       └ 미생성 → 재시도
            ─ 일시 오류 → 재시도 ─[같은 요청 식별자]→ 처리중
            ─ 접수 중지 → 확정 실패 ─[지점 변경]/[통화 변경]
            ─ 수령일시 불가 → 확정 실패 ─[수령일 변경]
            ─ 인증 만료 → 확정 실패 ─[이메일 다시 인증]

### 2.3 예약 취소
예약 상세 ─[예약 취소]→ 확인 ─[예약 취소]→ 처리중
  처리중 ─ 성공 → 완료 (방문 예정 안내 해제 · 취소 메일)
        ─ 유지 확정 → 확정 실패 ─[다시 취소 시도]→ 처리중
        ─ 응답 없음 → 결과 확인 필요 ─[취소 결과 다시 확인]→ 완료 / 확정 실패

### 2.4 예약 변경
- 고객 화면은 '예약 변경'이지만 내부는 **기존 예약 취소 + 신규 예약 생성(새 예약번호)**. 신규 예약 기준으로 2.1 재검증
- 변경 가능 구간 = 수령 2일 전(D-2)까지, 수령 전일(D-1)부터는 방문 확정·취소만

### 2.5 당일·전일 예약 즉시 확정
- 예약 접수 시 수령일까지 **1일 이하(당일 D-0, 전일 D-1 접수)**면 전일 확인 사이클이 불가하므로 **접수 즉시 방문 확정(컨펌)** — 전일 방문 예정 확인 메일 생략 (정책 §7.3)

### 2.6 비회원 로그인·가입
- 비회원 마이 → [로그인]/[회원가입] → 마이(회원) 복귀
- 예약 중 → 예약자 정보·이메일 인증 직후 **간편가입(비밀번호만)** → 예약 이어하기

## 3. Validation (화면별 검증)
| 화면 | 대상 | 규칙 | 실패 시 |
|---|---|---|---|
| 예약 조회 | 예약번호 + 이메일 | 둘 다 입력, 서버에서 두 값 모두 일치 | "예약번호와 이메일을 확인한 후 조회해 주세요." |
| 지점 탐색 | 지점명 검색 | 1자 이상, 부분 일치, 유인 지점만 | 결과 없음 |
| 통화 선택 | 통화 | 선택 지점·거래 방향 기준 수락 통화만 선택 가능(미취급 행 선택 불가) | 선택 비활성 |
| 이메일 인증 | 인증코드 | 유효시간 3분 · 재전송 최대 5회 · 초과 시 10분 잠금 | "인증번호 전송 한도를 초과했습니다. 10분 후 다시 시도해 주세요." |
| 예약 제출 | 요청 식별자 | 필수 · 처리중 재제출 차단 · 결과 불명 중 재제출 금지 | 결과 확인/재시도 상태 |
| 예약 제출 | 재검증 | 통화 수락 · 수령일시 가능 · (비회원) 이메일 인증 유효 | 확정 실패 유형별 |
| 가입 | 비밀번호 | 8자 이상 영문·숫자 조합 | 입력란 하단 오류 |
| 예약 취소 | 취소 | BOOKED이고 수령기한 전, 요청 직전 서버 상태 재검증 | 취소 불가 안내 |

## 4. 회원 데이터
- 가입은 예약 중 간편가입(예약자 정보·이메일 인증 직후, 비밀번호만 추가) 또는 마이에서 독립 가입
- 가입경로 값: 웹·예약 중 / 웹·예약 후 / 웹·마이
- 비밀번호: 8자 이상 영문·숫자 조합

## 5. 인증 · 로그인 진입점
| 진입점 | 화면 | 복귀 |
|---|---|---|
| 비회원 마이 | UI-W-4000 → 로그인/회원가입 | 마이(회원) |
| 예약 중 | UI-W-3400 내 간편가입(별도 로그인 화면 없음) | 예약 이어하기 |
- 로그인·회원가입 화면은 한 벌만 두고 진입 맥락에 따라 복귀 위치만 바꾼다
- 예약 중 입력한 이메일이 이미 가입된 경우: "로그인하시겠어요?" 안내 → 로그인 유도 + 비밀번호 찾기, 로그인 안 하면 비회원으로 계속(예약 안 막힘). (정책 §9.3)

## 6. 알림 (이메일)
- 웹 이용자는 **이메일만** 수신 (앱 푸시 없음)
- 예약 확인 메일, 비당일 예약의 전일 방문 예정 확인 메일 발송. **당일 예약·당일·전일 즉시 컨펌 건은 전일 방문 예정 확인 메일 제외**
- 취소·수령완료된 예약에는 남은 안내를 발송하지 않음
- 이메일 인증: 유효시간 3분 · 재전송 최대 5회 · 초과 시 10분 잠금 (국내 전화번호 인증 기준 준용)

## 7. CEMS 연동 (시재 표시)
- **용어는 '재고'가 아니라 '시재'로 통일 (D-30-18)** — 시재 = 지점이 보유한 통화별 현금
- **시재 표시(D-30-16)**: 컨펌(전일 방문 예정 확인의 '방문 예정' 응답, 또는 당일·전일 예약의 접수 즉시 컨펌) 후 Cash Flow 외국인예약 행에 예약 금액을 차감 예정(마이너스)으로 표시, 실제 차감은 수령(거래완료) 시점, 예약 접수는 시재와 무관. 컨펌 전 예약 미표시, 취소 시 즉시 해제
- 확장 화면: 취급통화·환전율 관리 '외국인예약 접수' 열, Cash Flow 외국인예약(매입/매각) 행, 본사 예약 가능 기간

## 8. 구현 보조 가정
> 승인 결정을 화면에 옮기며 둔 구현 보조 가정. 추가 사업 정책 확정을 뜻하지 않음.
### 8.1 예약 생성·취소
- 제출은 처리중/성공/확정 실패/결과 불명으로 구분, **결과 불명을 확정 실패로 안내하지 않음**
- 같은 요청 식별자로 재시도·조회해 중복 생성 방지. 최종 서버에서 지점·통화·방향·일시·금액·인증 재검증
- 실패 시 유효 입력은 유지하고 무효 단계만 재선택. 확인 메일 실패는 예약 생성 실패와 분리
- 취소는 예약 상태에서만. 수령완료/이미취소/자동취소는 최신 결과 안내, 중복 취소는 같은 결과로 처리
- **수령기한 = 수령일 당일이 끝나는 자정(익일 00:00).** 경과 시 자동 취소(AUTO)
### 8.2 통화·지점 변경
- 미취급 통화는 "해당 지점 미취급" 표기·선택 불가, 별도 '취급 지점 찾기' 안내 화면 없음 (D-30-04)
- 지점 변경 시 통화·금액은 가능 범위에서 보존, 수령일·시간은 새 지점 영업조건으로 재검증
- 무인기는 예약 대상 아님 — 환전예약 지점 탐색에 노출하지 않음(W-15). 무인환전기 위치(UI-W-5000)에서 선택 시 위치·"24시간 운영"만 안내 (D-30-20)
### 8.3 가입
- 가입 완료만으로 예약이 자동 확정되지 않음 — 이어서 신청정보 확인·[예약하기]
### 8.4 알림
- 웹은 이메일로 안내(§6). 당일·전일 즉시 컨펌 건은 전일 메일 생략. 취소·수령완료 예약에는 미발송
