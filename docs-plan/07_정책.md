# 정책 (Policies)

> 머니박스 외국인 환전예약 서비스의 운영 정책. 데이터/상태 상세는 `05_데이터모델.md`·`06_상태도.mermaid`, 실운영 요건은 `04_API.md` 참고.

## 1. 거래 방향
- **양방향 지원.** 고객이 신청 화면(금액 단계)에서 방향 토글로 선택한다.
  - **외화 → 원화 (매입, `BUY`)**: 고객이 외화 현금을 내고 원화를 받음. (기본값)
  - **원화 → 외화 (매각, `SELL`)**: 고객이 원화를 내고 외화 현금을 받음.
- 두 방향 모두 입력 금액은 **외화 기준**(받거나 내는 외화 금액). 예약 레코드 `transactionType`에 방향 기록.

## 2. 환율 (예약 시 미고정)
- **예약 시점에 환율을 고정하지 않는다.** 신청 화면은 특정 원화 금액을 확정하지 않고, "머니박스에서 환전하면 이만큼 더 받아요"(은행·키오스크·공항 대비)로 안내.
- **적용 환율 = 수령일 지점 전광판(기준) 환율.** 지점의 기존 전광판 시스템 값이며, 수령일(방문일) 값으로 POS에서 정산한다. (CEMS 내 별도 환율관리 화면은 제거됨)
- **전 고객 동일 단일 전광판 환율** — 금액대 구분 없음. 우대는 최고가 보장(아래)으로만.
- **현재 환율(참고 표시)**: 랜딩·예약 금액 화면에 실시간 현재 환율을 참고로 보여준다. 단 이는 **참고용 시세**이며, 지점에서 우대율이 적용된 실제 환율과 다를 수 있음을 **예약 직전 환율 하단·예약 내역**에 명시한다.

## 3. 최고가 보장 (회원가입)
- **회원가입 시 "최고가 보장" 제공** — 주변 시세보다 무조건 더 좋은 환율을 보장한다. 예약에 자동 적용.
- **적용 범위 한정**: 주변(동일 지역) 시세 기준. **타지역은 제외**(지역별 시세가 달라 보장 대상 아님) — 고객 화면에도 안내 문구 노출("주변 시세 기준 · 타지역 제외").
- 프로토타입 우대율 `WEB_COUPON_BONUS`(데모 +0.8%)로 전광판보다 더 얹어 정산.
- 미보유는 전광판 환율 그대로 적용(불이익 없음).
- 정산(POS 거래완료): 적용환율(전광판±보장)과 최종원화금액을 기록.
- 데이터 필드는 기존 `coupon`(boolean) 재사용 — 보장 적용 여부.
- (레거시) 예약시점 고정 건은 예약환율 vs 오늘환율 중 유리한 쪽 — 시드 데이터에만 존재.

## 4. 금액 한도
- **최소·최대·신청단위 한도 없음.** 양수 금액이면 자유롭게 신청 가능(금액 제한 제거).

## 5. 수령 · 예약
- **무결제 예약** → 지점 방문 시 **현금 결제**.
- **준비일수(리드타임) 제한 없음.** 수령 가능일: **예약일 ~ 최대 2주(14일)** 이내에서 자유 선택. 14일 초과는 `OUT_OF_WINDOW`.
- 수령 시 **신분증(여권) 지참** 필수(현장 본인 확인). 온라인 신분증 수집·본인인증 없음.
- 수령자명과 예약자명이 달라도 진행 가능(정책상 동일성 요구 안 함).

## 6. 취소 · 변경
- **`BOOKED` 상태에서만** 변경/취소 가능. 완료·취소 건은 불변.
- 변경(지점/통화/금액/방향/수령일) 시 재검증. (환율은 미고정 → 예약 시 재확정하지 않음)
- **취소 컷오프 없음** — 수령기한(당일 자정) 경과 전까지는 언제든 취소 가능.

## 7. 리마인더 응답 · 자동취소
- **리마인더 응답에 따라 처리한다:**
  - **"방문 예정" 확인** → 예약 유지(+재고 차감).
  - **"방문 안 함/취소" 응답 → 즉시 예약 취소.** (안 온다고 하면 바로 취소)
  - **무응답** → 수령기한까지 대기.
- **자동취소**: 수령기한(**수령예정일 당일 KST 자정**) 경과 & `BOOKED` → **자동취소**(`cancelReason=AUTO`). 방문예정확인을 했더라도 수령기한까지 미방문이면 동일하게 자동취소.
- **노쇼로 인한 신규예약 차단 없음** — 안내성으로만 운영. (프로토타입도 예약을 막지 않고 안내 문구만 노출)

## 8. 재고(시재)
- 예약 생성 시 **재고 미반영**(오버부킹 허용).
- 재고 경쟁은 **리마인더 "방문예정 확인" 시점**에 차감(consume). 소진 시 안내(상태 유지).
- 자동취소 시 복구: 방문예정확인(차감됨) 건은 복구, 미응답 건은 복구 없음.

## 9. 개인정보 · 동의
- 수집: **예약자명 · 이메일**(예약 처리·안내 목적). 관련 법령에 따라 보관 후 파기.
- 이메일 **OTP = 수신 가능 여부 확인**(본인인증 아님).
- 필수 **전체 동의 4종**: 이용약관 · 개인정보 수집·이용 · 개인정보 제3자 제공(수령 지점 운영사) · 노쇼 안내.
- **일반 예약은 온라인 신분증 수집·본인인증 없음.** 신분증 대조는 수령 시 지점(POS)에서만.
- **최고가 보장 회원가입에 한해** 여권 스캔(OCR로 영문 이름·생년월일 자동입력)을 받는다 — 우대 적용·본인 확인 목적. 프로토타입은 시뮬레이션(실제 파일 저장·OCR 아님).

## 10. 회원
- **예약에는 회원가입 불필요.**
- 선택 회원가입은 **최고가 보장**(주변 시세 우대) 적용용 — **이름 · 이메일 · 여권 스캔(OCR 자동입력: 영문 이름·생년월일)**. 프로토타입은 시뮬레이션(실제 계정 미생성).

## 11. 접근 · 다국어
- **무로그인 예약조회**: 예약번호 + 이메일 대조.
- 지원 언어(확정): **한국어 · 영어 · 중국어(간체·번체) · 일본어**. (현재 구현 ko/en, 中·日 확장 예정 — 키 구조 유지)
