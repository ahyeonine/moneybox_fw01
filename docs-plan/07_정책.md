# 정책 (Policies)

> 머니박스 외국인 환전예약 서비스의 운영 정책 정리. 수치는 프로토타입 목값이며 `// TODO`는 실제 정책 확정 필요. 데이터/상태 상세는 `05_데이터모델.md`·`06_상태도.mermaid`, 실운영 요건은 `04_API.md` 참고.

## 1. 거래 방향
- **원화 살 때(외화 → 원화, 매입)만 지원.** 고객이 외화 현금을 가져와 원화를 받는 방향.
- 매각(원화 → 외화)은 **미지원**. 고객 화면은 "환전구분"·방향 토글 미노출(기준환율 단일 표기).

## 2. 환율
- **전 고객 동일 단일 환율** — 회원/비회원·금액대 구분 없이 동일 우대(별도 우대율 없음). 프로모션이 있다면 쿠폰 등 별도 수단으로만.
- **신청("신청하기") 클릭 시점에 환율 픽스** → 이후 불변.
- 매입 스프레드율 수치 // TODO(현재 목환율, 프로토타입은 2분 자동변동).
- CEMS "외국인 웹사이트 매입환율"이 신청화면 환율에 실시간 반영.

## 3. 베스트레이트 보장
- **예약 시점보다 불리하지 않음.** 방문일에 환율이 더 좋아지면 **그날의 더 좋은 환율** 적용.
- 정산(POS 거래완료): **예약환율 vs 오늘환율 비교 → 원화구매에 유리한(원화 더 많은) 쪽** 적용, 실제적용환율·최종원화금액 기록.

## 4. 한도
- 통화별 **최소 환전금액**(전 지점 공통).
- 지점별 **건당 최대 환전금액**(환율 리스크 상한). CEMS 한도관리에서 관리.
- 웹 신청 **단위 올림**(unitStep) 적용. 금액 자동보정: 단위 올림 → 최대 초과 시 최대 → 최소 미만 시 최소.

- 최소/최대/단위/리드타임 실제 수치 // TODO.

## 5. 수령 · 예약
- **무결제 예약** → 지점 방문 시 **현금 결제**.
- 수령 가능일: **리드타임 이후 ~ 최대 2주(14일)**. 범위 밖은 `LEAD_TIME`/`OUT_OF_WINDOW`.
- 수령 시 **신분증(여권) 지참** 필수(현장 본인 확인). 온라인 신분증 수집·본인인증 없음.
- 수령자명과 예약자명이 달라도 진행 가능(정책상 동일성 요구 안 함).

## 6. 취소 · 변경
- **`BOOKED` 상태에서만** 변경/취소 가능. 완료·취소 건은 불변.
- 변경(지점/통화/금액/수령일) 시 재검증, 필요 시 환율 재픽스.
- **취소 컷오프 없음** — 수령기한(당일 자정) 경과 전까지는 언제든 취소 가능.

## 7. 노쇼 · 자동취소
- 수령기한(**수령예정일 당일 KST 자정**) 경과 & `BOOKED` → **자동취소**(`cancelReason=AUTO`). 리마인더 응답과 무관.
- **노쇼로 인한 신규예약 차단 없음** — 안내성으로만 운영. (프로토타입에는 누적 차단 시연 코드가 남아 있으나 정책상 미적용)

## 8. 재고(시재)
- 예약 생성 시 **재고 미반영**(오버부킹 허용).
- 재고 경쟁은 **리마인더 "방문예정 확인" 시점**에 차감(consume). 소진 시 안내(상태 유지).
- 자동취소 시 복구: 방문예정확인(차감됨) 건은 복구, 미응답 건은 복구 없음.

## 9. 개인정보 · 동의
- 수집: **예약자명 · 이메일**(예약 처리·안내 목적). 관련 법령에 따라 보관 후 파기.
- 이메일 **OTP = 수신 가능 여부 확인**(본인인증 아님).
- 필수 **전체 동의 4종**: 이용약관 · 개인정보 수집·이용 · 개인정보 제3자 제공(수령 지점 운영사) · 노쇼 안내.
- 온라인 신분증 업로드/사전수집 없음.

## 10. 회원
- **예약에는 회원가입 불필요.**
- 선택 회원가입은 **환율 최저가 보장 쿠폰** 수령용(이름 · 이메일 인증). 프로토타입은 시뮬레이션(실제 계정 미생성).

## 11. 접근 · 다국어
- **무로그인 예약조회**: 예약번호 + 이메일 대조.
- 지원 언어(확정): **한국어 · 영어 · 중국어(간체·번체) · 일본어**. (현재 구현 ko/en, 中·日 확장 예정 — 키 구조 유지)
