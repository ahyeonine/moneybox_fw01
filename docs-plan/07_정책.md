# 정책 (Policies)

> 머니박스 외국인 환전예약 서비스의 운영 정책. 데이터/상태 상세는 `05_데이터모델.md`·`06_상태도.mermaid`, 실운영 요건은 `04_API.md` 참고.

## 1. 거래 방향
- **양방향 지원.** 고객이 신청 화면(금액 단계)에서 방향 토글로 선택한다.
  - **외화 → 원화 (매입, `BUY`)**: 고객이 외화 현금을 내고 원화를 받음. (기본값)
  - **원화 → 외화 (매각, `SELL`)**: 고객이 원화를 내고 외화 현금을 받음.
- 두 방향 모두 입력 금액은 **외화 기준**(받거나 내는 외화 금액). 예약 레코드 `transactionType`에 방향 기록.

## 2. 환율 (예약 시 미고정)
- **예약 시점에 환율을 고정하지 않는다.** 신청 화면은 특정 원화 금액을 확정하지 않고, "머니박스에서 환전하면 이만큼 더 받아요"(타 환전 채널·키오스크·공항 대비, **예시 수치**)로 안내.
- **과장광고 주의**: "가장 저렴/최고가 보장/무조건" 등 단정·최상급 표현은 지양한다. 비교는 특정 업권(은행 등)을 지목하지 않고 **추상적 표현(타 환전 채널)** 을 쓰고, 수치는 **예시이며 통화·시점·지점에 따라 달라질 수 있음**을 함께 안내한다.
- **적용 환율 = 수령일 지점 전광판(기준) 환율.** 지점의 전광판 시스템 값이며, 수령일(방문일) 값으로 POS에서 정산한다. (CEMS에 별도 환율관리 화면은 없음)
- **전 고객 동일 단일 전광판 환율** — 금액대 구분 없음. 우대는 최고가 보장(아래)으로만.
- **현재 환율(참고 표시)**: 랜딩·예약 금액 화면에 실시간 현재 환율을 참고로 보여준다. 단 이는 **참고용 시세**이며, 지점에서 우대율이 적용된 실제 환율과 다를 수 있음을 **예약 직전 환율 하단·예약 내역**에 명시한다.

## 3. 회원 우대 (현장 재량 우대)
- **회원가입 시 "회원 우대" 대상**이 된다. **예약에 자동 적용되는 고정 우대율은 없다.** 수령 시 지점 현장에서 **상황에 맞춰 우대 환율을 적용**한다(재량 우대).
- 우대폭은 **수령 시점 현장 상황**(시세·재고 등)에 따라 결정 — 고정값·사전 확정 아님.
- **표현 주의**: "최고가 보장/무조건" 같은 단정 표현 대신 **"회원 우대"** 로 안내한다(과장광고 방지, 2번 참고).
- 미가입은 전광판 환율 그대로 적용(불이익 없음).
- 화면에는 **현재 환율(참고 시세)** 을 보여주되, 지점에서 우대가 적용된 실제 환율과 다를 수 있음을 안내한다(2번 참고).
- 데이터 필드는 `coupon`(boolean) 재사용 — **회원 우대 대상 여부**. 프로토타입 정산 시뮬레이션은 `WEB_COUPON_BONUS`(데모 +0.8%)를 우대 예시로 사용(실제는 현장 재량).
- 예약시점 고정(`FIXED`) 건은 예약환율 vs 오늘환율 중 유리한 쪽으로 정산 — 시드 데이터에 한함.

## 4. 금액 한도
- **최소·최대·신청단위 한도 없음.** 양수 금액이면 자유롭게 신청 가능.

## 5. 수령 · 예약
- **무결제 예약** → 지점 방문 시 **현금 결제**.
- **준비일수(리드타임) 제한 없음.** 수령 가능일: **예약일(오늘) 이후 자유 선택**. **기본은 기간 제한 없음(무제한)** — 상한이 지정된 경우에만 그 범위를 벗어난 날짜가 `OUT_OF_WINDOW`.
- **예약 가능 기간(수령일 상한)은 본사(CEMS 본사관리자)에서만 설정.** 지점은 변경 불가. CEMS 좌측 메뉴 **[예약 가능 기간 설정 (본사)]** 전용 화면에서 **제한 없음(무제한) / 일수 지정(오늘부터 최대 N일, 1~60일)** 중 선택하며(기본 무제한), 값은 고객 사이트 수령일 선택 범위·예약조회 변경에 즉시 반영.
- 수령 시 **신분증(여권) 지참** 필수(현장 본인 확인). 온라인 신분증 수집·본인인증 없음.
- 수령자명과 예약자명이 달라도 진행 가능(정책상 동일성 요구 안 함).
- **무인환전기(머니24h)**: 지도에 **위치 안내용으로만 표시**(지점과 다른 색 마커). 24시간 무인 운영이며 예약 없이 이용. **예약·수령은 유인지점에서만** 진행된다(무인기에서는 예약 처리 안 함).

## 6. 취소 · 변경
- **`BOOKED` 상태에서만** 변경/취소 가능. 완료·취소 건은 불변.
- 변경(지점/통화/금액/방향/수령일) 시 재검증. (환율은 미고정 → 예약 시 재확정하지 않음)
- **취소 컷오프 없음** — 수령기한(당일 자정) 경과 전까지는 언제든 취소 가능.

## 7. 리마인더 응답 · 자동취소
- **리마인더 응답에 따라 처리한다:**
  - **"방문 예정" 확인** → 예약 유지(+재고 차감).
  - **"방문 안 함/취소" 응답 → 즉시 예약 취소.** (안 온다고 하면 바로 취소)
  - **무응답** → 수령기한까지 대기.
- **자동취소**: 수령기한(**수령예정일 당일 KST 자정**) 경과 & `BOOKED` → **자동취소**(`cancelReason=AUTO`). 방문예정확인을 했더라도 수령기한까지 미방문이면 동일하게 자동취소.
- **노쇼로 인한 신규예약 차단 없음** — 안내성으로만 운영. (프로토타입도 예약을 막지 않고 안내 문구만 노출)

## 8. 재고(시재)
- 예약 생성 시 **재고 미반영**(오버부킹 허용).
- 재고 경쟁은 **리마인더 "방문예정 확인" 시점**에 차감(consume). 소진 시 안내(상태 유지).
- 자동취소 시 복구: 방문예정확인(차감됨) 건은 복구, 미응답 건은 복구 없음.

## 9. 개인정보 · 동의
- 수집: **예약자명 · 이메일**(예약 처리·안내 목적). 관련 법령에 따라 보관 후 파기.
- **이메일 인증(수신 가능 여부 확인)**: 예약·회원가입 시 입력한 이메일로 인증번호를 발송해 **실제 수신 가능한 이메일인지 확인**한다(본인인증 아님). 인증 완료해야 예약/가입 진행 가능. 이메일을 변경하면 재인증. 프로토타입은 시뮬레이션(인증번호를 화면에 노출).
- **마케팅 정보 수신 동의(선택)**: 할인 쿠폰·환율 알림·이벤트 소식 수신 동의 여부를 예약·회원가입 화면에서 선택(필수 아님). 예약 레코드 `marketingConsent`에 기록.
- **온라인 신분증 수집·본인인증 없음.** 신분증 대조는 수령 시 지점(POS)에서만.
- **최고가 보장 회원가입**은 이름·이메일·비밀번호만 받는다(계정용). 프로토타입은 시뮬레이션(실제 계정 미생성).

## 10. 회원
- **예약에는 회원가입 불필요.**
- 선택 회원가입 — **이름 · 이메일 · 비밀번호**. 프로토타입은 시뮬레이션(실제 계정 미생성).
- **회원 혜택**: 회원 우대(수령 시 현장 우대 환율) + 할인 쿠폰 · 환율 알림 · 회원 전용 서비스(유도용 마케팅 문구).
- **가입 유도**: 예약 화면에 혜택 배너("지금 회원가입하고 혜택 받기"). 예약자 정보(이름·이메일) 입력 후에는 "비밀번호만 추가하면 회원가입 완료"로 전환 — 이름·이메일 자동 채움.
- **회원 예약 간소화**: 회원은 이름·이메일을 이미 보유하므로 **예약자 정보 입력 단계를 건너뛴다.** 금액·수령일 입력 후 바로 예약이 완료된다. (비회원은 금액·수령일 입력 → 예약자 정보 입력 → 예약)

## 11. 접근 · 다국어
- **무로그인 예약조회**: 예약번호 + 이메일 대조.
- 지원 언어: **한국어 · 영어**(기본 영어). i18n 키 구조로 언어 확장 가능.
