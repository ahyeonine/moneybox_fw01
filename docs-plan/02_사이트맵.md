# 사이트맵 — 해외환전예약 서비스

(구조도는 상단 시각화 다이어그램 참고)

## 외국인 웹사이트 헤더 네비게이션 (그룹형 드롭다운)

`환전 | 부가서비스 | 위치 ▾ | 회사 | 문의 | 신청내역조회` — 위치만 드롭다운(호버+클릭), 나머지는 단독 링크. 모바일은 햄버거 접이식 메뉴. 모든 페이지는 사이트 기존 디자인 컴포넌트 재사용 + 다국어(i18n ko/en).

| 상위 메뉴 | 하위 | 라우트 | 설명 |
|---|---|---|---|
| 환전 | (단독) | `/site/book` | 지점 수령 환전 예약 플로우(STEP A~, BookingFlow) — 클릭 시 바로 진입 |
| 부가서비스 | (단독·외부) | (외부) `https://imoneybox.cafe24.com/shop3/` | 자사 eSIM 웹사이트로 새 탭 연결(`target="_blank"`). ※ 선불카드는 제거됨 — 부가서비스는 eSIM 단독 외부 링크 |
| 위치 ▾ | 지점 | `/site/branches` | 오프라인 지점(직원 상주) 정보 열람(BranchesPage): 검색+리스트+지도. 리스트의 "환전 예약하기" → `/site/book?branch=<id>` |
| 위치 ▾ | 키오스크 | `/site/kiosks` | 무인 환전기 찾기(KiosksPage): 검색+지역칩+리스트+구글맵 임베드 + "가까운 키오스크 찾기"(Geolocation) |
| 회사 | (단독) | `/site/about` (별칭 `/site/company`) | 회사 소개(AboutPage): 소개·주요 서비스·특징·운영 네트워크·회사 정보. 상단에 "기존과 동일" 안내 문구 노출 |
| 문의 | (단독·외부) | (외부) 채널톡 | 채널톡 상담으로 새 탭 연결(`target="_blank"`). `CONTACT_URL` 상수로 관리 — 실제 채널톡 워크스페이스 URL로 교체 필요 |
| 신청내역조회 | (단독) | `/site/lookup` | 신청내역 조회(LookupPage): 로그인 없이 **이름 + 이메일**로 같은 이메일의 신청내역 리스트 조회 → 상세에서 방문 예정 확인/변경/취소 |

### 네비 미노출(기존 유지, 다른 경로로 접근)
| 페이지 | 라우트 | 접근 경로 |
|---|---|---|
| 지점수령예약 | `/site/book` | 홈 히어로 카드 · 지점 페이지 "환전 예약하기" (상세는 03_예약플로우_화면정의서) |
| eSIM | `/site/esim` | 홈 히어로 카드 (외부 연동) |

> 지도: 키오스크/지점 페이지는 **인터랙티브 지도(구글맵 iframe embed, `https://www.google.com/maps?q=<위도>,<경도>&output=embed`)** 사용 — 이메일의 정적 이미지 지도(StaticBranchMap)와는 별개 방식.
> 참고: 별도 산출물로 동일 콘텐츠의 단일 파일 랜딩(`company-intro.html`)이 저장소 루트에 있으나, 사이트 메뉴/라우팅과 연결된 실제 페이지는 위 React 페이지다. (선불카드 랜딩은 제거됨)

## 공통 요소 (전 페이지 적용)

| 요소 | 상태 |
|---|---|
| 로그인/회원/본인인증 | 없음 — 회원가입·로그인 없이 이용. 별도 본인인증도 없음(이메일 OTP는 이메일 수신 가능 여부 확인용) |
| 다국어 전환 | 영어(기본)/중국어(간체·번체)/일본어, eSIM 제외 전체 |
| 약관·정책 고지 | 이용약관·개인정보처리방침·노쇼 안내, 다국어 필요 |
