# 사이트맵 — 해외환전예약 서비스

(구조도는 상단 시각화 다이어그램 참고)

## 페이지 목록

| 페이지 | 하위 페이지 | 설명 |
|---|---|---|
| 지점수령예약 | 예약 플로우 상세 (8단계) | 다단계 환전 예약 진입점, 상세는 03_예약플로우_화면정의서 |
| 카드 | 없음 | **외국인 웹사이트 "카드" 메뉴 → `/site/prepaid` (PrepaidCardPage)**. 사이트 기존 디자인 컴포넌트 재사용, 다국어(i18n ko/en). 올인원 선불카드 소개: 두 지갑(선불·결제/교통), 카드 기본 정보, 충전 방법, 무인기/지점 수령, FAQ. 실제 구매/충전은 범위 밖(안내 위주) |
| 예약조회 | 예약상세(취소·변경) | 예약번호+연락처로 비회원 조회 |
| eSIM | 없음 | 기존 페이지 외부 연동 |
| 회사소개 | 없음 | **외국인 웹사이트 "회사 소개" 메뉴 → `/site/about` (AboutPage)**. 사이트 기존 디자인 재사용, 다국어(i18n ko/en). 회사 소개·주요 서비스·서비스 특징·운영 네트워크·회사 정보(등록 실제 정보)·문의/제휴 |

> 참고: 별도 산출물로 동일 콘텐츠의 단일 파일 랜딩(`prepaid-card-landing.html`, `company-intro.html`)이 저장소 루트에 있으나, 외국인 웹사이트 메뉴/라우팅과 연결된 실제 페이지는 위 React 페이지(`/site/prepaid`, `/site/about`)다.

## 공통 요소 (전 페이지 적용)

| 요소 | 상태 |
|---|---|
| 로그인 | 1차 오픈 포함 여부 `[결정 필요]` — 미포함 가정하고 비회원 플로우를 기본 골격으로 설계 |
| 다국어 전환 | 영어(기본)/중국어(간체·번체)/일본어, eSIM 제외 전체 |
| 약관·정책 고지 | 이용약관·개인정보처리방침·노쇼 안내, 다국어 필요 |
