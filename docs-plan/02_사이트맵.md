# 사이트맵 — 해외환전예약 서비스

(구조도는 상단 시각화 다이어그램 참고)

## 외국인 웹사이트 헤더 네비게이션 (5개)

`카드 | 키오스크 | 지점 | 회사 | 문의` — 모든 페이지는 사이트 기존 디자인 컴포넌트 재사용 + 다국어(i18n ko/en).

| 메뉴 | 라우트 | 설명 |
|---|---|---|
| 카드 | `/site/prepaid` (별칭 `/site/card`) | 올인원 선불카드 소개(PrepaidCardPage): 두 지갑(선불·결제/교통), 카드 기본 정보, 충전 방법, 무인기/지점 수령, FAQ. 실제 구매/충전은 범위 밖(안내 위주) |
| 키오스크 | `/site/kiosks` | 무인 환전기 찾기(KiosksPage): 검색 + 지역칩 + 리스트 + 구글맵 임베드(iframe). "가까운 키오스크 찾기"(Geolocation)로 최단거리 자동 정렬/선택. 키오스크 목데이터(24시간)는 `src/data/kiosks.js` |
| 지점 | `/site/branches` | 오프라인 지점(직원 상주) 정보 열람(BranchesPage): 검색+리스트+지도. 예약 플로우 STEP A와 별개. 리스트의 "환전 예약하기" → `/site/book?branch=<id>` 로 지점 선택된 상태로 예약 플로우 진입 |
| 회사 | `/site/about` (별칭 `/site/company`) | 회사 소개(AboutPage): 소개·주요 서비스·특징·운영 네트워크·회사 정보(등록 실제 정보)·문의/제휴 |
| 문의 | `/site/contact` | 간단 문의 폼(ContactPage): 이름/이메일/문의유형/내용. 제출 시 실제 전송 없이 "접수되었습니다" 안내만(프로토타입) |

### 네비 미노출(기존 유지, 다른 경로로 접근)
| 페이지 | 라우트 | 접근 경로 |
|---|---|---|
| 지점수령예약 | `/site/book` | 홈 히어로 카드 · 지점 페이지 "환전 예약하기" (상세는 03_예약플로우_화면정의서) |
| 예약조회 | `/site/lookup` | 직접 링크/푸터 (예약번호+연락처 비회원 조회) |
| eSIM | `/site/esim` | 홈 히어로 카드 (외부 연동) |

> 지도: 키오스크/지점 페이지는 **인터랙티브 지도(구글맵 iframe embed, `https://www.google.com/maps?q=<위도>,<경도>&output=embed`)** 사용 — 이메일의 정적 이미지 지도(StaticBranchMap)와는 별개 방식.
> 참고: 별도 산출물로 동일 콘텐츠의 단일 파일 랜딩(`prepaid-card-landing.html`, `company-intro.html`)이 저장소 루트에 있으나, 사이트 메뉴/라우팅과 연결된 실제 페이지는 위 React 페이지다.

## 공통 요소 (전 페이지 적용)

| 요소 | 상태 |
|---|---|
| 로그인 | 1차 오픈 포함 여부 `[결정 필요]` — 미포함 가정하고 비회원 플로우를 기본 골격으로 설계 |
| 다국어 전환 | 영어(기본)/중국어(간체·번체)/일본어, eSIM 제외 전체 |
| 약관·정책 고지 | 이용약관·개인정보처리방침·노쇼 안내, 다국어 필요 |
