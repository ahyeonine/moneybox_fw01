## 외국인 웹사이트 헤더 네비게이션 (그룹형 드롭다운)

`환전 | 서비스 ▾ | 위치 ▾ | 회사 | 문의` — 데스크톱은 드롭다운(호버+클릭), 모바일은 햄버거 접이식 메뉴. 모든 페이지는 사이트 기존 디자인 컴포넌트 재사용 + 다국어(i18n ko/en).

| 상위 메뉴 | 하위 | 라우트 | 설명 |
|---|---|---|---|
| 서비스 ▾ | eSIM | (외부) `https://imoneybox.cafe24.com/shop3/` | 자사 eSIM 웹사이트로 새 탭 연결(`target="_blank"`). 헤더 드롭다운·푸터 공통 |
| 서비스 ▾ | 카드 | `/site/prepaid` (별칭 `/site/card`) | 올인원 선불카드 소개(PrepaidCardPage): 두 지갑, 카드 기본 정보, 충전 방법, 무인기/지점 수령, FAQ |
| 환전 | (단독) | `/site/book` | 지점 수령 환전 예약 플로우(STEP A~, BookingFlow) — 클릭 시 바로 진입 |
| 위치 ▾ | 지점 | `/site/branches` | 오프라인 지점(직원 상주) 정보 열람(BranchesPage): 검색+리스트+지도. 리스트의 "환전 예약하기" → `/site/book?branch=<id>` |

| 문의 | (단독) | `/site/contact` | 간단 문의 폼(ContactPage): 제출 시 접수 안내만(프로토타입) |

### 네비 미노출(기존 유지, 다른 경로로 접근)
| 페이지 | 라우트 | 접근 경로 |
|---|---|---|
| 지점수령예약 | `/site/book` | 홈 히어로 카드 · 지점 페이지 "환전 예약하기" (상세는 03_예약플로우_화면정의서) |
| 예약조회 | `/site/lookup` | 직접 링크/푸터 (예약번호+연락처 비회원 조회) |
| eSIM | `/site/esim` | 홈 히어로 카드 (외부 연동) |

> 지도: 키오스크/지점 페이지는 **인터랙티브 지도(구글맵 iframe embed, `https://www.google.com/maps?q=<위도>,<경도>&output=embed`)** 사용 — 이메일의 정적 이미지 지도(StaticBranchMap)와는 별개 방식.
> 참고: 별도 산출물로 동일 콘텐츠의 단일 파일 랜딩(`prepaid-card-landing.html`, `company-intro.html`)이 저장소 루트에 있으나, 사이트 메뉴/라우팅과 연결된 실제 페이지는 위 React 페이지다.
