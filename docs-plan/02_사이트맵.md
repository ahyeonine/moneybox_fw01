# 사이트맵

## 헤더 네비게이션
`환전 | 부가서비스 | 위치 ▾ | 회사 | 문의 | 신청내역조회` (위치만 드롭다운, 모바일 햄버거)

| 메뉴 | 라우트 | 설명 |
|---|---|---|
| 환전 | `/site/book` | 지점수령 예약 플로우(상세 03) |
| 부가서비스 | (이동 없음) | 클릭 시 "→ eSIM 외부 사이트로 이동" 안내 텍스트만 표시(프로토타입, 실제 이동 없음). 선불카드 제거됨 |
| 위치 ▾ 지점 | `/site/branches` | 지점 정보(검색+리스트+지도) |
| 위치 ▾ 키오스크 | `/site/kiosks` | 무인 환전기(구글맵 임베드 + GPS) |
| 회사 | `/site/about` | 회사소개 — "기존과 동일" 안내 문구만 노출(내용 생략, 디자인 참고) |
| 문의 | (이동 없음) | 클릭 시 "→ 채널톡 상담으로 이동" 안내 텍스트만 표시(프로토타입, 실제 이동 없음) |
| 신청내역조회 | `/site/lookup` | 이름+이메일로 신청내역 조회 → 방문확인/변경/취소 |

- 홈(`/site`): 히어로 + 실시간 기준환율 티커까지만. 그 아래는 "기존 페이지와 동일"(공항수령 제외 → 디자인 참고) 안내로 대체.
- 지도: 키오스크/지점은 구글맵 iframe, 이메일은 정적 지도(StaticBranchMap).

## 공통
- 로그인/회원/본인인증 없음(이메일 OTP는 수신 확인용)
- 다국어: 영(기본)/중(간·번)/일, eSIM 제외
- 약관·개인정보·노쇼 안내 고지(다국어)
