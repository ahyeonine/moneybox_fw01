## 1. 예약 플로우 (고객)

| No | 시나리오 | 기대 결과 |
|---|---|---|
| 1 | 통화별 최소금액 미만 입력 | 다음 단계 진행 불가, 에러 안내 |
| 2 | 지점 최대금액(하드리밋) 초과 입력 | 자동으로 최대금액으로 보정 |
| 3 | 신청금액 단위에 안 맞는 금액 입력 (예: 단위 20인데 35 입력) | 올림해서 가장 가까운 단위 배수로 자동 보정 (40) |
| 4 | 보정 순서 검증 (단위보정 후 결과가 최대 초과) | 단위 올림 → 최대 초과 확인 → 최대값으로 재보정 |
| 5 | 리드타임 이전 날짜 선택 시도 | 캘린더에서 선택 불가 |
| 6 | 최대 2주(14일) 초과 날짜 선택 시도 | 캘린더에서 선택 불가 |
| 7 | 이메일 형식 오류 입력 | 에러 메시지, 다음 단계 불가 |
| 8 | 최종확인 직전 재고 소진 케이스 | 마감 안내, 지점선택 화면으로 유도 |
| 9 | "신청하기" 클릭 시점과 최종확인 시점 환율 동일성 확인 | 신청하기 클릭 시점에 환율이 픽스되고, 최종확인엔 그 값이 그대로 노출 |
| 10 | 정책동의 미체크 상태에서 예약완료 시도 | 진행 불가 |
| 11 | 예약완료 후 예약번호 발급 형식 확인 | 형식에 맞게 채번(목데이터 기준) |
| 12 | 새로고침 후 진행 중이던 예약 상태 확인 | 임시저장 없음 — 처음부터 재입력 |
| 12-1 | 노쇼 누적 N회 이상인 이메일로 예약자정보 입력 시도 | 예약 불가 안내, 다음 단계 진행 불가 |
| 12-2 | 같은 지점·통화·수령일 마지막 재고에 두 사용자가 동시에 "신청하기" | 먼저 완료한 쪽만 성공, 나중 쪽은 최종확인에서 재검증 실패 안내 |
| 12-3 | 수령예정일 당일, 한국시간 자정 경과 시점 확인 | 고객 현지시간과 무관하게 KST 자정 기준으로 무응답 예약 자동취소 |
