# 데이터 모델

> 프로토타입(`src/data/*`, `src/store/*`) 기준. 백엔드 스키마 설계 참고용 타입/제약.

## 1. Reservation (예약) — 핵심 엔티티

| 필드 | 타입 | 필수 | 설명 |
|---|---|---|---|
| `reservationNo` | string | ✔ | 노출용 예약번호 `RSV-YYYYMMDD-####` |
| `status` | enum | ✔ | `BOOKED` \| `COMPLETED` \| `CANCELLED` |
| `transactionType` | enum | ✔ | **`BUY`(매입·원화구매) 고정** — 외국인 웹사이트는 원화 살 때만 지원 |
| `branchId` | FK→Branch | ✔ | 수령 지점 |
| `currency` | string(3) | ✔ | ISO 4217 |
| `rate` | decimal(18,4) | ✔ | 예약 시점 픽스 환율(KRW/1단위, 전 고객 동일) |
| `foreignAmount` | decimal(18,2) | ✔ | 외화 금액 |
| `krwAmount` | bigint | ✔ | `round(foreignAmount * rate)` |
| `customerName` | string | ✔ | 예약자명(여권 영문, 대문자) |
| `email` | string | ✔ | 이메일(형식검증 + OTP 수신확인, 본인인증 아님) |
| `pickupDate` / `pickupTime` | date / HH:mm | ✔ | 수령 예정일·시간 |
| `createdAt` / `processedAt` | datetime | ✔/ | 신청 / 완료 일시 |
| `idVerified` | boolean | ✔ | 현장 신분증 대조 완료(기존 POS 흐름, 시뮬레이션) |
| `reminderStatus` | enum | ✔ | `NONE` \| `CONFIRMED` \| `NO_RESPONSE` |
| `cancelReason` | enum\|null | | `AUTO`(노쇼) \| `CUSTOMER` \| null |

**규칙**
- `rate`는 **신청("신청하기") 클릭 시점에 픽스**, 이후 불변. 회원/비회원 구분 없이 동일 환율.
- 방향은 `BUY`(원화구매)만 지원 → 고객 화면은 "환전구분" 미노출, 기준환율도 방향 토글 없이 단일 노출("원화 살 때").
- **베스트레이트 보장**: 거래완료(POS) 시 예약환율 vs 오늘환율 중 원화구매에 유리한 쪽 적용.
- 노쇼: `cancelReason='AUTO'` 카운트(`countNoShow`)는 안내·통계용. **정책상 신규예약 차단 없음**(프로토타입에 누적 차단 시연 코드는 남아 있음).
- 인덱스 제안: `UNIQUE(reservationNo)`, `INDEX(email)`, `INDEX(branchId,pickupDate,status)`, `INDEX(status,pickupDate)`.

## 2. Branch (지점)

`id` · `name{ko,en}` · `address{ko,en}` · `leadTimeDays` · `currencyLimits: 통화코드→{min,max}` · `lat,lng`(V2 거리계산·지도).
`currencyLimits` 키 목록 = 취급통화. 정책(07_정책): 최소·최대·신청단위는 **지점이 CEMS 한도관리에서 통화별 설정** — 최소 기본 USD 100 상당액, 최대는 지점 설정(상한 USD 9,999 상당액). 준비일수(leadTime) 제한 없음(수령 범위 최대 2주). *(프로토타입 목값은 실제와 다를 수 있음)*

## 3. Rate (환율)

프로토타입 고정 목환율(`src/data/rates.js`). 백엔드: `currency · baseRate · appliedRate · effectiveAt`. 예약 생성 시 `appliedRate` 스냅샷을 `Reservation.rate`로 픽스.

## 4. 어드민 한도 (CEMS)

- **CurrencyMinAmount**: 통화별 최소(전 지점 공통) — 시드 `POLICY_MIN_AMOUNTS`.
- **BranchMaxAmount**: 지점별 건당 최대(리스크 상한) — `(branchId,currency)`.
- 통화 마스터 18종: `CURRENCY_ORDER` (+ `CURRENCY_META` 국기·명칭, `MOCK_RATES`).

## 5. Enum
```
ReservationStatus = BOOKED | COMPLETED | CANCELLED
TransactionType   = BUY (원화구매, 유일 지원) | SELL (매출 — 데이터상 예약, 웹 미지원)
ReminderStatus    = NONE | CONFIRMED | NO_RESPONSE
```

## 6. Out of Scope / 변경 이력
- **회원(User)**: 기존 "없음(확정)" → 현재 **선택적 회원가입**(쿠폰 전용, 이름·이메일+인증). 예약에는 불필요, 프로토타입 시뮬레이션(실제 계정 미생성).
- Payment/PG(무결제·현장결제), 온라인 신분증 업로드: 범위 밖. 노쇼 제재·우대율·취소 컷오프: **없음으로 확정**(07_정책 참고).
