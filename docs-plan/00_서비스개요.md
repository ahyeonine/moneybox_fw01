# 서비스 개요 (전체 정리)

> 머니박스 외국인 환전예약 서비스의 **전체 그림**을 한 문서로 정리한 것. 세부는 각 문서로 연결한다.
> IA `01_IA.md` · 구조도 `02_구조도.mermaid` · 플로우 `03_플로우.mermaid` · API `04_API.md` · 데이터 `05_데이터모델.md` · 상태 `06_상태도.mermaid` · 정책 `07_정책.md`

## 1. 한 줄 정의

외국인(인바운드) 고객이 **온라인으로 환전을 예약(무결제)** 하고, 지정 지점을 방문해 **신분증 확인 후 현장에서 전액 결제·수령**하는 서비스.
**환율은 예약 시점에 고정하지 않으며**, 수령일 지점 전광판(외국인 웹사이트 매입) 환율로 정산한다. **회원가입 쿠폰**을 보유하면 전광판 환율보다 우대해 준다.

- **거래 방향**: 원화 살 때(외화 → 원화, 매입)만. 매각(원화 → 외화)은 미지원.
- **환율**: 예약 시 미고정 → 수령일 전광판 환율. 회원가입 쿠폰 시 전광판보다 우대.
- **결제/회원**: 무결제 예약 + 현장 전액결제. 로그인 없이 예약 가능(회원가입은 쿠폰 수령용 선택).
- **본인확인**: 온라인 본인인증 없음. 이메일은 수신 확인용. 신분증 대조는 수령 시 지점(POS)에서.
- **프로토타입**: 백엔드 없음(목데이터 + 프론트 상태). React + Vite, GitHub Pages 배포.

## 2. 사용자와 서피스

서로 다른 사용자용 시스템을 데모 편의상 한 앱의 상단 탭으로 묶었다.

| 서피스 | 경로 | 사용자 | 한 줄 |
|---|---|---|---|
| **외국인 웹사이트** | `/site` | 인바운드 고객 | 랜딩 → **금액 → 지점 → 예약자 정보 → 완료**. 예약조회 포함 |
| **CEMS (지점 어드민)** | `/cems` | 본사/지점 운영자 | 예약·환율 관리. **각 지점이 로그인해 사용** |
| **POS** | `/pos` | 지점 직원 | 예약 검색 → 신분증 대조 → 거래완료(전광판/쿠폰 정산) |
| **이메일** | `/email` | 운영 | 예약확인·리마인더 발송 이력/미리보기 |
| **기획문서** | `/docs` | 내부 | 이 문서 뷰어(`docs-plan/`) |

> 고객 사이트는 하나다. (초기 V1[예약시점 환율고정]·V2[환율미고정] 두 안을 검토했으나, **환율 미고정 + 쿠폰 우대** 안으로 단일화했다.)

## 3. 핵심 시나리오 (엔드투엔드)

```
[고객] 외국인 웹사이트에서 예약
   → 금액(통화·금액) 입력 · "은행·키오스크·공항보다 평균 X% 더" 안내
   → 지점 선택(검색·내 위치·추천) → 예약자 정보(이름·이메일·수령일) → 예약 완료(RSV 번호)
   → 환율은 미고정. 회원가입 쿠폰이 있으면 "전광판보다 우대"로 표시·정산
        │
        ▼
[운영] CEMS · 외국인 환전예약관리에 예약 표시(환율=전광판/쿠폰 표기)
   → 리마인더 응답: 방문예정=유지·재고차감 / 방문안함=즉시취소 / 무응답=수령기한 대기
        │
        ▼
[지점] 고객 방문 → POS에서 예약 검색 → 신분증(여권) 대조
   → 정산: 수령일 전광판 환율 적용(쿠폰 보유 시 전광판보다 우대) → 현장 결제 → 거래완료(COMPLETED)
```

- **웹 → CEMS**: 예약 생성 시 CEMS 예약관리에 즉시 반영.
- **CEMS ↔ POS**: 같은 예약 레코드 공유. POS 거래완료가 상태를 COMPLETED로 전이하고 실제 적용환율·최종원화를 기록.
- **자동취소**: 수령기한(수령예정일 당일 KST 자정) 경과 & 미방문 → 자동취소(`AUTO`). SimBar "하루 넘기기"로 시연.

## 4. 서피스별 상세

### 외국인 웹사이트 (`/site`)
- **랜딩**: "은행보다 좋은 환율" 카피 + 환율 위젯(통화·금액 → "은행·키오스크·공항보다 +X% 더") + **환율 비교 강조 섹션**(채널별 막대) + 가치 3종 · 이용방법 3단계 · 오늘의 환율 · CTA.
- **예약 플로우**: 금액 → 지점(검색·내 위치·추천, Leaflet/OSM) → 예약자 정보(이름·이메일·수령일) → 완료(RSV 번호).
- **환율 미고정**: 예약 시 환율을 확정하지 않음. 회원가입 쿠폰 시 "전광판보다 우대" 표기.
- **예약조회**: 예약번호+이메일 → 변경/취소/방문예정확인.
- **회사 소개**: 스토리텔링 About 페이지.

### CEMS · 지점 어드민 (`/cems`)
- 각 지점이 로그인해 자기 지점을 운영(프로토타입은 로그인 지점 1곳 대표).
- **예약관리**: 외국인 환전예약 리스트. 환율 미고정 예약은 "전광판(·쿠폰)"으로 표기.
- **환율관리**: 통화별 외국인 웹사이트 **매입환율(전광판)** 설정. 매입만 지원.
- (금액 한도 관리 없음 — 최소·최대·신청단위 제한 제거)

### POS (`/pos`)
- 예약 검색 → 거래처리(신분증 대조 → **정산** → 거래완료).
- 정산: 전광판(수령일) 환율 적용, 쿠폰 보유 시 전광판보다 우대. (예약시점 고정 건이 있다면 예약환율 vs 오늘환율 중 유리한 쪽)

### 이메일 (`/email`)
- 예약확인·리마인더·지점취소 등 발송 이메일 이력·미리보기(시뮬레이션).

## 5. 확정 정책 (요약)

전문 `07_정책.md`. 프로토타입 동작도 아래에 맞춰 정렬돼 있다.

| 항목 | 정책 |
|---|---|
| 거래 방향 | 원화 살 때(매입)만. 매각 미지원 |
| 환율 | **예약 시 미고정 → 수령일 지점 전광판(외국인 웹사이트 매입) 환율** 적용. 전 고객 동일(지점이 CEMS에서 설정) |
| 쿠폰 우대 | **회원가입 쿠폰 보유 시 전광판 환율보다 우대**(데모 +0.8%). 미보유는 전광판 환율 |
| 금액 한도 | **없음** — 최소·최대·신청단위 제한 제거 |
| 리드타임 | 제한 없음(예약일 당일부터). 수령 범위 예약일 ~ 최대 2주(14일) |
| 취소 | 컷오프 없음(수령기한 경과 전까지 가능) |
| 리마인더 | 방문안함→즉시취소 / 방문예정→유지·재고차감 / 무응답→수령기한 대기 후 자동취소 |
| 노쇼 | 신규예약 차단 없음(안내만) |
| 회원 | 예약엔 불필요. 선택 회원가입은 **쿠폰(전광판보다 우대)** 수령용(이름·이메일) |
| 다국어 | 한·영·중(간체·번체)·일 (현재 구현 ko/en, 기본 en) |

## 6. 데이터·상태 (요약)

- **핵심 엔티티 Reservation**: 예약번호·상태·통화·`rateMode`(FIXED\|BOARD)·`coupon`·환율(BOARD는 null)·외화금액·예약자명·이메일·수령일·리마인더상태·취소사유. 상세 `05_데이터모델.md`.
- **상태**: `BOOKED → COMPLETED`(지점 거래완료) / `BOOKED → CANCELLED`(고객취소·방문안함응답·자동취소). `06_상태도.mermaid`.
- **재고(시재)**: 예약 생성 시 미반영 → 리마인더 방문예정확인 시점에 차감.
