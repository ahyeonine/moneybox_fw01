# 서비스 개요 (전체 정리)

> 머니박스 외국인 환전예약 서비스의 **전체 그림**을 한 문서로 정리한 것. 세부는 각 문서로 연결한다.
> IA `01_IA.md` · 구조도 `02_구조도.mermaid` · 플로우 `03_플로우.mermaid` · API `04_API.md` · 데이터 `05_데이터모델.md` · 상태 `06_상태도.mermaid` · 정책 `07_정책.md`

## 1. 한 줄 정의

외국인(인바운드) 고객이 **온라인으로 환전을 예약(무결제)** 하고, 지정 지점을 방문해 **신분증 확인 후 현장에서 전액 결제·수령**하는 서비스.
**환율은 예약 시점에 고정하지 않으며**, 수령일 지점 전광판(기준) 환율로 정산한다. **회원가입 시 "최고가 보장" 회원** — 수령 시 지점 현장에서 상황에 맞춰 최대한 우대한다(고정 우대율·자동적용 아님).

- **거래 방향**: 양방향 — 외화 → 원화(매입, `BUY`, 기본) / 원화 → 외화(매각, `SELL`). 금액 단계에서 토글로 선택.
- **환율**: 예약 시 미고정 → 수령일 전광판 환율. 회원가입 시 **최고가 보장**(수령 시 현장 우대).
- **결제/회원**: 무결제 예약 + 현장 전액결제. 로그인 없이 예약 가능(회원가입은 최고가 보장 적용용 선택).
- **본인확인**: 온라인 본인인증 없음. 이메일은 수신 확인용. 신분증 대조는 수령 시 지점(POS)에서.
- **프로토타입**: 백엔드 없음(목데이터 + 프론트 상태). React + Vite, GitHub Pages 배포.

## 2. 사용자와 서피스

서로 다른 사용자용 시스템을 데모 편의상 한 앱의 상단 탭으로 묶었다.

| 서피스 | 경로 | 사용자 | 한 줄 |
|---|---|---|---|
| **외국인 웹사이트** | `/site` | 인바운드 고객 | 랜딩 → **지역 → 지점 → 금액 → 예약자 정보 → 완료**. 예약조회 포함 |
| **CEMS (지점 어드민)** | `/cems` | 본사/지점 운영자 | 예약 관리(설정 탭 비활성). **각 지점이 로그인해 사용** |
| **POS** | `/pos` | 지점 직원 | 신분증 스캔 → 예약 조회 → 거래완료(최고가 보장 시 우대 정산) |
| **이메일** | `/email` | 운영 | 예약확인·리마인더 발송 이력/미리보기 |
| **기획문서** | `/docs` | 내부 | 이 문서 뷰어(`docs-plan/`) |

> 고객 사이트는 하나다. 예약 시 환율을 고정하지 않고, 수령일 전광판 환율로 정산하며 회원가입 시 **최고가 보장**으로 우대한다.

## 3. 핵심 시나리오 (엔드투엔드)

```
[고객] 외국인 웹사이트에서 예약
   → 지역(서울·부산·그 외) → 지점 선택(검색·내 위치·추천 · 상세: 영업시간·전화·지도)
   → 금액(방향 토글 외화↔원화 · 통화·금액) · "머니박스에서 환전하면 이만큼 더 받아요" 안내
   → 예약자 정보(이름·이메일·수령일) → 예약 완료(RSV 번호)
   → 환율은 미고정. 최고가 보장 회원은 수령 시 현장에서 우대(자동적용 아님)
        │
        ▼
[운영] CEMS · 외국인 환전예약관리에 예약 표시(환율=전광판·최고가 보장 표기)
   → 리마인더 응답: 방문예정=유지·재고차감 / 방문안함=즉시취소 / 무응답=수령기한 대기
        │
        ▼
[지점] 고객 방문 → POS 신분증 스캔 → 예약 조회·대조
   → 정산: 수령일 전광판 환율 적용(최고가 보장 시 우대) → 현장 결제 → 거래완료(COMPLETED)
```

- **웹 → CEMS**: 예약 생성 시 CEMS 예약관리에 즉시 반영.
- **CEMS ↔ POS**: 같은 예약 레코드 공유. POS 거래완료가 상태를 COMPLETED로 전이하고 실제 적용환율·최종원화를 기록.
- **자동취소**: 수령기한(수령예정일 당일 KST 자정) 경과 & 미방문 → 자동취소(`AUTO`). SimBar "하루 넘기기"로 시연.

## 4. 서피스별 상세

### 외국인 웹사이트 (`/site`)
- **랜딩**: "은행보다 좋은 환율" 카피 + 지역 위젯(서울·부산·그 외 + "머니박스에서 환전하면 이만큼 더 받아요") + **환율 비교 강조 섹션**(채널별 막대) + 가치 3종 · 이용방법 3단계 · 현재 환율(참고) · CTA.
- **예약 플로우**: 지역(서울·부산·그 외) → 지점(검색·내 위치·추천·상세[영업시간·전화·지도], Leaflet/OSM) → 금액(방향 토글·통화·금액·현재 환율) → 예약자 정보(이름·이메일·수령일) → 완료(RSV 번호).
- **환율 미고정**: 예약 시 환율을 확정하지 않음. 회원가입 시 "최고가 보장(수령 시 현장 우대)" 표기. 현재 환율은 참고 시세이며 지점 우대 적용 환율과 다를 수 있음을 안내.
- **예약조회**: 예약번호+이메일 → 변경/취소/방문예정확인.
- **회사 소개**: 스토리텔링 About 페이지.

### CEMS · 지점 어드민 (`/cems`)
- 각 지점이 로그인해 자기 지점을 운영(프로토타입은 로그인 지점 1곳 대표).
- **예약관리**: 외국인 환전예약 리스트(외국인 환전예약관리·본사관리자). 환율 미고정 예약은 "전광판(·최고가 보장)"으로 표기.
- **설정**: 탭 비활성(클릭 불가). 예약 시 환율을 고정하지 않고 수령일 전광판(기준) 환율을 적용하므로 별도 환율 설정 화면은 없다.
- 금액 한도 관리 없음(최소·최대·신청단위 제한 없음).

### POS (`/pos`)
- 환전예약(국내/해외 탭) → 신분증 스캔 우선 → 예약 조회(국내=한국인 목록·건너뛰기 / 해외=이름·생년월일 일치·유사 매칭) → 거래처리(정산 → 거래완료).
- 정산: 전광판(수령일) 환율 적용, 최고가 보장 보유 시 우대. (예약시점 고정 건은 예약환율 vs 오늘환율 중 유리한 쪽)

### 이메일 (`/email`)
- 예약확인·리마인더·지점취소 등 발송 이메일 이력·미리보기(시뮬레이션).

## 5. 확정 정책 (요약)

전문 `07_정책.md`. 프로토타입 동작도 아래에 맞춰 정렬돼 있다.

| 항목 | 정책 |
|---|---|
| 거래 방향 | 양방향 — 외화→원화(매입·BUY, 기본) / 원화→외화(매각·SELL). 금액 단계 토글 |
| 환율 | **예약 시 미고정 → 수령일 지점 전광판(기준) 환율** 적용. 전 고객 동일(지점 전광판 시스템 값) |
| 최고가 보장 | **회원가입 시 수령 시 현장에서 상황에 맞춰 최대한 우대**(고정 우대율·자동적용 아님). 미가입은 전광판 환율 |
| 금액 한도 | **없음**(최소·최대·신청단위 제한 없음) |
| 리드타임 | 제한 없음(예약일 당일부터). 수령 범위 예약일 ~ 예약 가능 기간(기본 14일, **본사에서만 설정**) |
| 취소 | 컷오프 없음(수령기한 경과 전까지 가능) |
| 리마인더 | 방문안함→즉시취소 / 방문예정→유지·재고차감 / 무응답→수령기한 대기 후 자동취소 |
| 노쇼 | 신규예약 차단 없음(안내만) |
| 회원 | 예약엔 불필요. 선택 회원가입은 **최고가 보장(수령 시 현장 우대)** 적용용(이름·이메일·비밀번호) |
| 다국어 | 한국어·영어 지원(기본 영어). i18n 키 구조로 언어 확장 가능 |

## 6. 데이터·상태 (요약)

- **핵심 엔티티 Reservation**: 예약번호·상태·통화·`rateMode`(FIXED\|BOARD)·`coupon`·환율(BOARD는 null)·외화금액·예약자명·이메일·수령일·리마인더상태·취소사유. 상세 `05_데이터모델.md`.
- **상태**: `BOOKED → COMPLETED`(지점 거래완료) / `BOOKED → CANCELLED`(고객취소·방문안함응답·자동취소). `06_상태도.mermaid`.
- **재고(시재)**: 예약 생성 시 미반영 → 리마인더 방문예정확인 시점에 차감.

## 7. 기술·운영에 필요한 것 (요약)

실제 운영 요건은 `04_API.md` 체크리스트 참고: 백엔드+DB · 전광판 환율 피드 · 재고 · 이메일 발송 · (선택)회원/최고가 보장 · 지도/지오코딩 · 자동취소 스케줄러 · CEMS/POS 연동 · 비기능 요건.

- **스택**: React 18 + Vite 5 + React Router 6(HashRouter) · Leaflet(지도) · marked/mermaid(문서 렌더).
- **배포**: `main` push → GitHub Actions → GitHub Pages. Vite `base='/moneybox_fw01/'`.
- **다른 계정으로 이전**: 저장소 최상단 `README.md`의 "다른 계정에서 이어받아 쓰기" 참고.
