# 알림/리마인더 시나리오 및 템플릿 — 해외환전예약 서비스

발송 채널: **이메일 단일** (메신저ID 없음)

## 1. 발송 시점 및 트리거

| 시점 | 트리거 | 목적 |
|---|---|---|
| 예약완료 직후 | 예약 생성 성공 | 예약 내용 확인, 예약번호 재고지 |
| 수령 전일 | 배치(스케줄러)로 매일 발송 | 방문 리마인드, 원터치 방문예정/취소 응답 유도 |
| 수령 당일, 무응답 상태였던 건 | 수령기한(당일) 임박 | 마지막 리마인드, 이후 자동취소됨을 고지 |
| 자동취소 발생 시 | 수령기한 경과 | 취소 사실 고지 |
| 고객이 직접 취소 시 | 예약조회에서 취소 처리 | 취소 확인 |

## 2. 무응답 처리 로직 (재확인)
- 전일 리마인더에 무응답이어도 즉시 취소하지 않음
- 수령기한(=수령예정일 당일) 경과 시에만 자동취소
- 명시적 "취소" 응답은 즉시 처리

## 3. 템플릿 (한국어 기준 초안 — 다국어 버전은 08_다국어_번역대상_리스트 참고)

### 3-1. 예약완료 안내
```
제목: [MONEY BOX] 환전 예약이 완료되었습니다 (예약번호: {예약번호})

{예약자명}님, 환전 예약이 완료되었습니다.

- 예약번호: {예약번호}
- 지점: {지점명}
- 통화/금액: {통화} {거래금액}
- 예약환율: {예약환율}
- 원화금액: {원화금액}
- 수령 예정일: {수령예정일}

예약 조회/취소는 아래 링크에서 가능합니다.
[예약 조회하기]

⚠ 방문이 어려우실 경우 미리 취소해 주세요. 수령 예정일이 지나도록 방문하지 않으실 경우 예약이 자동 취소되며, 반복될 경우 서비스 이용에 제한이 있을 수 있습니다.
```

### 3-2. 수령 전일 리마인더
```
제목: [MONEY BOX] 내일 환전 수령 예정이에요 (예약번호: {예약번호})

{예약자명}님, 내일({수령예정일}) {지점명}에서 환전 수령 예정입니다.

[✅ 방문 예정입니다]   [❌ 취소할게요]

방문이 어려우신데 응답을 안 주셔도 오늘 안에는 취소되지 않습니다.
단, 수령 예정일 당일까지 응답이 없으면 자동으로 취소돼요.
```

### 3-3. 수령 당일 무응답 리마인더
```
제목: [MONEY BOX] 오늘 환전 수령일이에요 — 응답이 필요해요

{예약자명}님, 오늘({수령예정일}) 방문 예정이신가요?
오늘 안에 응답이 없으면 예약이 자동으로 취소됩니다.

[✅ 방문 예정입니다]   [❌ 취소할게요]
```

### 3-4. 자동취소 안내
```
제목: [MONEY BOX] 예약이 자동 취소되었습니다 (예약번호: {예약번호})

{예약자명}님의 예약이 수령 예정일 경과로 자동 취소되었습니다.
다시 예약하시려면 아래 버튼을 이용해 주세요.

[다시 예약하기]
```

## 4. 링크 처리
- "방문 예정입니다" / "취소할게요" 버튼: 이메일 내 원터치 링크(로그인 없이 예약번호 기반 토큰으로 처리)
- 프로토타입에서는 실제 이메일 발송 없이, 예약조회 화면의 상태값 변경으로 시뮬레이션해도 무방
