# IA (정보구조 · 화면 목록)

> 머니박스 프로토타입의 서피스·네비게이션·화면 목록. 전체 개요는 `00_서비스개요.md`, 구조 다이어그램은 `02_구조도.mermaid` 참고.

## 서피스 (상단 데모 탭)

| 탭 | 경로 | 사용자 | 설명 |
|---|---|---|---|
| 외국인 웹사이트 | `/site` | 인바운드 고객 | 랜딩 → 금액 → 지점 → 예약자 정보 → 완료. 환율 미고정 + 쿠폰 우대 |
| CEMS (어드민) | `/cems` | 본사/지점 운영자 | 예약·환율 관리 |
| POS | `/pos` | 지점 직원 | 예약 검색 → 거래처리(전광판/쿠폰 정산) |
| 이메일 | `/email` | (데모) | 알림·리마인더 발송 이력 |
| 기획문서 | `/docs` | 내부 | 본 문서 뷰어 |

> 실제로는 서로 다른 사용자용 별도 시스템이며, 데모 편의를 위해 한 앱에서 탭으로 전환한다.
> 고객 사이트는 단일(초기 V1/V2 검토 → 환율 미고정+쿠폰 안으로 단일화).

## 외국인 웹사이트 (`/site`)

단일 페이지에서 뷰 전환(home · flow · lookup · about).

- **랜딩(home)**: 히어로(🛡️ 베스트레이트 보장) + 환율 위젯(통화·금액 → "은행·키오스크·공항보다 평균 X% 더") + 가치 3종 · 이용방법 3단계 · 오늘의 환율 · CTA
- **예약(flow)**: ① 금액 입력(통화·금액, 환율 미고정 안내) → ② 지점 선택(검색 OSM Nominatim · 내 위치 Geolocation · 인기 위치 · 전체, Leaflet 지도·거리순) → ③ 예약자 정보(이름·이메일·수령일) → ④ 완료(RSV 번호)
- **예약조회(lookup)**: 예약번호+이메일 → 변경/취소/방문예정확인
- **회사 소개(about)**: 스토리텔링

헤더: 로고(홈) · 예약조회 · 회사 소개 · 환전 예약(CTA) · 언어선택.
푸터: 다크 푸터(그룹 링크 + 연락처 + 언어).
쿠폰: 금액/정보 단계의 "회원가입하고 더 좋은 환율" 배너 → 가입(이름·이메일) 시 쿠폰 지급 → 전광판보다 우대.

## CEMS (`/cems`)

- `/cems/reservations` — 외국인 환전예약관리(환율 미고정 예약은 "전광판·쿠폰" 표기)
- `/cems/hq` — 본사 예약관리
- `/cems/settings/rates` — 환율관리(외국인 웹사이트=**매입만**, 전광판 매입환율)

## POS (`/pos`)

- `/pos` — 홈, `/pos/reservation` — 예약검색/결과, `/pos/transaction` — 거래처리(신분증 대조 → **정산**: 전광판 환율 적용, 쿠폰 보유 시 우대)

## 언어

프로토타입은 한국어/영어 2종(기본 영어). 실제 서비스는 한·영·중(간체·번체)·일 확장(키 구조 유지). 문자열: `src/i18n/strings.js`.
