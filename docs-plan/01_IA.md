# IA (정보구조 · 화면 목록)

> 머니박스 프로토타입의 서피스·네비게이션·화면 목록. 전체 개요는 `00_서비스개요.md`, 구조 다이어그램은 `02_구조도.mermaid` 참고.

## 서피스 (상단 데모 탭)

| 탭 | 경로 | 사용자 | 설명 |
|---|---|---|---|
| 외국인 웹사이트 | `/site` | 인바운드 고객 | 랜딩 → 지역 → 지점 → 금액(방향 토글) → 예약자 정보 → 완료. 환율 미고정 + 회원 우대 |
| CEMS (어드민) | `/cems` | 본사/지점 운영자 | 예약 관리(설정 탭 비활성) |
| POS | `/pos` | 지점 직원 | 신분증 스캔 → 예약 조회 → 거래처리(전광판·회원 우대 정산) |
| 이메일 | `/email` | (데모) | 알림·리마인더 발송 이력 |
| 기획문서 | `/docs` | 내부 | 본 문서 뷰어 |

> 실제로는 서로 다른 사용자용 별도 시스템이며, 데모 편의를 위해 한 앱에서 탭으로 전환한다.
> 고객 사이트는 단일이며, 예약 시 환율 미고정 · 회원 우대 모델을 따른다.

## 외국인 웹사이트 (`/site`)

단일 페이지에서 뷰 전환(home · flow · lookup · about).

- **랜딩(home)**: 히어로(더 좋은 환율) + 지역 위젯(서울·부산·그 외 + "머니박스에서 환전하면 이만큼 더 받아요") + 가치 3종 · 이용방법 3단계 · 현재 환율(참고 시세 안내: 지점 우대 적용 환율과 다를 수 있음) · CTA
- **예약(flow)**: ① 지역 선택(서울·부산·그 외 — 대표 지역 외는 "그 외"로 묶음) → ② 지점 선택(검색 OSM Nominatim · 내 위치 Geolocation · 인기 위치 · 전체, Leaflet 지도·거리순 · **지도에 머니24h 무인기 위치 표시(위치 안내용·예약 불가)** · **지점 상세: 영업시간·전화·미니지도**) → ③ 금액·수령일(방향 토글 외화↔원화 · 통화·금액 · 수령일 · 현재 환율 표시, 환율 미고정 안내) → ④ 예약자 정보(이름·이메일 + 이메일 인증 · 마케팅 수신 동의 · **회원은 건너뜀**) → ⑤ 완료(RSV 번호)
- **예약조회(lookup)**: 예약번호+이메일 → 변경/취소/방문예정확인
- **회사 소개(about)**: 스토리텔링

헤더: 로고(홈) · 예약조회 · 회사 소개 · 환전 예약(CTA) · 언어선택.
푸터: 다크 푸터(그룹 링크 + 연락처 + 언어).
회원 우대: 금액/정보 단계의 "회원 우대 받기" 배너 → 가입(이름·이메일·비밀번호 + 이메일 인증) → 회원 우대 대상, 수령 시 현장에서 우대(자동적용 아님).

## CEMS (`/cems`)

- `/cems/reservations` — 외국인 환전예약관리(환율 미고정 예약은 "전광판·회원 우대" 표기)
- `/cems/hq` — 본사 예약관리(전 지점 조회)
- `/cems/policy` — **예약 가능 기간(수령일 최대 N일) 설정(본사 전용)** → 고객 사이트 수령일 범위에 반영
- `/cems/settings` — 설정(탭 비활성/클릭 불가). 예약 시 환율 미고정·수령일 전광판 적용이라 별도 환율 설정 화면은 없다.

## POS (`/pos`)

- `/pos` — 홈, `/pos/reservation` — 환전예약(국내/해외 탭, **두 탭 모두 신분증 스캔 우선**), `/pos/transaction` — 거래처리(정산: 전광판 환율, 회원 우대 시 우대)
  - 두 탭 모두 하단 **건너뛰기** → 예약 목록 → 선택 시 기존 거래처리 화면(`/pos/reservation/flow` 플레이스홀더). **모든 예약건에 이름 표시**
  - 건너뛰기 목록 구분: **국내예약=한국인(한글 이름) / 해외예약=외국인(영문 이름)**
  - 해외예약 스캔: 이름·생년월일 **일치/유사(오입력·편집거리 ≤ 2)** 예약 조회 → 선택 시 거래처리

## 언어 · 진입 경로

- 한국어·영어 지원(기본 영어). i18n 키 구조(`src/i18n/strings.js`)로 언어 확장 가능.
- **통합웹(m-box.com)에서 외국어 선택 시 외국인 페이지로 분기**: 국내 대표 통합웹에서 사용자가 언어를 외국어(EN·中文·日本語 등)로 선택하면 **이 외국인 전용 페이지(`/site`)로 자동 이동**한다. 국내 고객은 통합웹, 외국인은 이 페이지로 진입 경로가 갈린다.
- 이 프로토타입의 **[Customer Website] 탭이 그 외국인 페이지**에 해당한다. 통합웹 화면 자체는 프로토타입 범위 밖이며, 진입 경로는 외국인 사이트 상단 메모(DevNote)로 설명한다.
