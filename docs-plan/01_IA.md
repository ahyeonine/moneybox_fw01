# IA (정보구조 · 화면 목록)

> 머니박스 프로토타입의 서페이스·네비게이션·화면 목록. 전체 개요는 `00_서비스개요.md`, 구조 다이어그램은 `02_구조도.mermaid` 참고.

## 서페이스 (상단 데모 탭)

| 탭 | 경로 | 사용자 | 설명 |
|---|---|---|---|
| 외국인 웹사이트 (V1) | `/site` | 인바운드 고객 | 대표 고객 사이트. 지점 먼저 → 신청 |
| 외국인 사이트 2안 (V2) | `/site2` | 인바운드 고객 | WOWPASS풍. 금액 먼저 → 지점 선택(검색·지도) |
| CEMS (어드민) | `/cems` | 본사/지점 운영자 | 예약·환율·한도 관리 |
| POS | `/pos` | 지점 직원 | 예약 검색 → 거래처리(베스트레이트 정산) |
| 이메일 | `/email` | (데모) | 알림·리마인더 템플릿/발송 이력 |
| 기획문서 | `/docs` | 내부 | 본 문서 뷰어 |

> 실제로는 서로 다른 사용자용 별도 시스템이며, 데모 편의를 위해 한 앱에서 탭으로 전환한다.

## V1 · 외국인 웹사이트 (`/site`)

- `/site` — 홈: 히어로(서비스 가치 순환 타이포 · 🛡️ 손해 없는 환전=베스트레이트 보장) + 실시간 기준환율 + 이용방법/혜택/인기지점/FAQ/CTA
- `/site/book` — 예약 플로우(지점 → 신청 → 예약자정보 → 최종확인 → 동의 → 완료). **원화 살 때(외화→원화)만 지원.** 상단에 환율보장 쿠폰 배너(→ 선택적 회원가입)
- `/site/lookup` — 예약 조회(예약번호+이메일), 변경/취소/방문예정확인
- `/site/branches` — 지점 정보(검색·지도), `/site/kiosks` — 무인환전기(머니24h)
- `/site/about` — 회사 소개(스토리텔링), `/site/esim` — eSIM(외부)

네비: 환전(예약) · 부가서비스▾ · 위치▾(지점/무인환전기) · 회사 · 문의▾ · 예약조회 · 언어선택.
푸터: 그룹형(머니박스/서비스/정보/지원) + 브랜드·언어·법인정보.

## V2 · 외국인 사이트 2안 (`/site2`)

- 단일 페이지 2단계: **① 금액 입력**(통화·금액→예상 원화) → **② 지점 선택**
- 지점 선택: 위치 **검색(OpenStreetMap Nominatim)** + **내 위치로 찾기(Geolocation)** + 인기 위치 + 전체 지점. 선택 시 **Leaflet 지도**(내 위치·지점 마커) + 거리순 추천
- "예약" → V1 예약 플로우(`/site/book`)로 **지점·통화·금액 전달**해 신청 단계 진입
- 다크 푸터(OrangeSquare풍)

## CEMS (`/cems`)

- `/cems/reservations` — 외국인 환전예약관리(신규예약 리스트)
- `/cems/hq` — 본사 예약관리
- `/cems/settings/rates` — 환율관리(외국인 웹사이트=**매입만** 지원, 매각 미지원 잠금)
- `/cems/settings/limits` — 한도관리(통화별 최소·지점별 최대)

## POS (`/pos`)

- `/pos` — 홈, `/pos/reservation` — 예약검색/결과, `/pos/transaction` — 거래처리(신분증 대조 → **베스트레이트 정산**)

## 언어

프로토타입은 한국어/영어 2종. 실제 서비스는 영어(기본)/중국어/일본어 확장(키 구조 유지). 문자열: `src/i18n/strings.js`.
