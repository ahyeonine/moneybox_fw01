# QA 테스트 시나리오 (핵심)

## 예약 플로우
- 최소금액 미만 → 진행 불가 / 최대 초과 → 최대로 보정 / 단위 불일치 → 상위 단위 올림(올림 후 최대 초과 시 최대로 재보정)
- 리드타임 이전·14일 초과 날짜 선택 불가 / 이메일 형식 오류 → 진행 불가
- 환율은 "신청하기" 시점 픽스, 최종확인엔 그 값 노출
- OTP 미인증·동의 4종 미완료 → 진행 불가
- 노쇼 N회 이상 이메일 → 예약자정보 단계에서 차단
- 새로고침 → 임시저장 없음, 재입력

## 조회/취소/변경 (이름+이메일)
- 없는 건 조회 → "결과 없음" / 같은 이메일 다건 → 리스트 / 완료·취소건 → 취소·변경 버튼 숨김
- 예약 상태 취소 → 확인모달 후 처리 / 변경 → 재고 재확인

## 노쇼/리마인더
- 전일 무응답 → 자동취소 안 됨, 기본목록(방문확인만) 숨김("전체보기"만 노출)
- 수령기한(당일 KST 자정) 경과까지 무응답 → 자동취소(재고 미반영이라 복구 불필요)
- "방문 예정" → 시재 반영·차감, 목록 노출 / "취소" → 즉시 취소·복구
- 방문예정확인 후 미방문 → 자동취소하되 재고는 복구, 노쇼 카운트 동일

## CEMS
- 필터 조합·방문확인만/전체보기 토글(기본 방문확인만)
- 한도관리: 최소/최대 토글, 원화 일괄입력 → 통화별 자동환산, 개별 수정
- 최대금액 9,999 USD 상당 초과 설정 → 저장 불가
- 환율 변경 → STEP B 실시간 반영 / 2분 경과 → 자동 갱신
- 본사관리자: 지점 필터·컬럼, 전 지점 조회

## POS
- 환전예약: 내국인 탭 → "기존 환전예약 사이트" 안내 / 외국인 탭 → 검색 폼
- 검색: 이름·수령일·예약번호 끝4자리(단독 매칭), 이메일 검색 없음
- 거래처리: 신분증 대조(명의 불일치 진행) 전 완료 시도 → 차단, 대조 후 완료 → 상태 "완료"
- 거래완료 → CEMS 즉시 동기화 / 고객 취소 → POS 목록 제외, CEMS 상태만 취소

## 전역/홈
- 언어 전환(한/영) 필수 영역 반영 / 데브노트 고정·토글
- 홈: 히어로 2카드(지점수령/eSIM) + 기준환율 티커 + "기존 페이지와 동일" 안내(그 아래 콘텐츠 없음)
- 회사 페이지: "기존과 동일" 안내만
