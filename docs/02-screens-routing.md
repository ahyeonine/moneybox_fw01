# 화면 목록 & 라우팅 구조 (Screens & Routing)

> 라우팅은 `react-router-dom` (`src/App.jsx`) 기준. 모든 화면은 공통 `Layout`(상단바 + 네비 + 언어토글) 하위에 렌더됩니다.

---

## 1. 라우트 맵

| 경로 | 컴포넌트 | 대상 | 설명 |
|---|---|---|---|
| `/` | `Home` | 고객 | 랜딩. 예약/조회 CTA |
| `/book` | `BookingFlow` | 고객 | **지점수령예약 8단계 위저드** |
| `/lookup` | `LookupPage` | 고객 | 예약조회 → 취소/변경. 쿼리 `?no=&email=` 딥링크 지원 |
| `/operator` | `OperatorConsole` | 지점 운영자 | 탭: 신규예약 리스트 / 거래처리 + 시뮬레이션 바 |
| `/about` | `AboutPage` | - | 회사소개 (더미, Out of Scope) |
| `/esim` | `EsimPage` | - | eSIM 외부링크 자리 (Out of Scope) |
| `*` | `Home` | - | 폴백 |

> 운영자 화면은 프로토타입 단순화를 위해 `/operator` 단일 라우트 + 내부 탭 상태로 구성했습니다.
> 실제 서비스에서는 인증/권한 분리와 함께 `/operator/prep`, `/operator/tx` 등으로 분리 권장.

## 2. 화면 상세

### 2.1 `/book` — 지점수령예약 (8단계)

단일 페이지 위저드. 스텝 상태는 컴포넌트 로컬 state (`draft`), 완료 시에만 전역 store에 커밋.
**중도 이탈/새로고침 → 처음부터 (임시저장 없음, 요구사항대로).**

| 단계 | 컴포넌트 | 입력/노출 | "다음" 활성 조건 |
|---|---|---|---|
| 1. 지점선택 | `Step1` | 지점 리스트(4개 목데이터) | 지점 선택됨 |
| 2. 통화선택 | `Step2` | 환전구분(매입/매출) + 선택 지점 취급통화만 노출 | 통화 선택됨 |
| 3. 금액입력 | `Step3` | 숫자입력, 실시간 원화환산 | 통화별 최소~최대 범위 내 |
| 4. 수령일선택 | `Step4` | 캘린더 (min=오늘+리드타임, max=오늘+30일) | 날짜 선택됨 |
| 5. 예약자정보 | `Step5` | 여권영문명 + 이메일 | 이름/이메일 형식 유효 |
| 6. 최종확인 | `Step6` | 요약 + **환율 픽스** | 항상 활성 |
| 7. 정책동의 | `Step7` | 노쇼안내 + 개인정보 동의 체크 | 전체 동의 |
| 8. 예약완료 | `Step8` | 예약번호 발급, 완료 화면 | - |

**예외 플로우**
- 금액 미달/초과 → 인라인 에러 + "다음" 비활성
- 재고 소진 → 안내 화면 후 "처음부터 다시" (데모: `B003 + VND` 조합)
- 재고소진 판정은 2단계(통화선택) 직후 `isSoldOut()` 로 수행

### 2.2 `/lookup` — 예약조회

- 예약번호 + 이메일 조회 (`findReservation`)
- 상태 뱃지 표시. **`BOOKED` 일 때만** 취소/변경 노출
- 취소 → 확인 모달 → `CANCELLED`
- 변경 → 인라인 폼(지점/통화/금액/날짜 재입력) → 저장. 지점 변경 시 취급통화 자동 보정
- 예약완료 화면에서 `?no=&email=` 로 진입 시 자동 조회

### 2.3 `/operator` — 운영자 콘솔

- 상단 **시뮬레이션 바**(`SimBar`): 기준일 표시, 하루 넘기기, 자동취소 실행, 데이터 초기화
- **탭 1 · 신규예약 리스트(`PrepList`)**: 시재준비용
  - 컬럼: 수령예정일 / 예약번호 / 예약자명 / 통화 / 환전구분 / 외화금액 / 예약환율 / 원화금액 / 리마인더 / 상태
  - 정렬: 수령예정일 오름차순
  - 필터: 수령일 범위, 상태
  - 상단 요약 카드: 매출 준비(통화별 외화 합) / 매입 준비(원화 합)
  - 리마인더 응답별 노출 규칙 적용 + "숨김 항목 표시" 토글
- **탭 2 · 거래처리(`TransactionProcess`)**: 예약번호 조회 → 신분증 대조 체크 → 거래완료(`COMPLETED`)

## 3. 컴포넌트 트리 (요약)

```
main.jsx
└─ BrowserRouter
   └─ I18nProvider
      └─ ReservationProvider          ← 전역 예약 상태 + 시뮬레이션 기준일
         └─ App (Routes)
            └─ Layout                  ← 상단바 / 네비 / 언어토글 / 푸터
               ├─ Home
               ├─ BookingFlow          ← Stepper + Step1..8
               ├─ LookupPage           ← Detail / ChangeForm / Modal
               ├─ OperatorConsole      ← SimBar + Tabs
               │  ├─ PrepList
               │  └─ TransactionProcess
               ├─ AboutPage
               └─ EsimPage
```

## 4. 다국어 (i18n)

- 한국어(`ko`) + 영어(`en`) 2개 언어. `src/i18n/strings.js` 키-값 사전, `useI18n().t(key)` 로 사용.
- 언어 선택은 `localStorage(mbox.lang)` 저장.
- 실제 서비스 확장(중국어 간·번체, 일본어)은 `strings.js` 에 언어 키만 추가하면 됨.
