김포 발렛 수령 · 화면 흐름 (와이어프레임)

m-box.com "공항 수령"에 발렛을 선택 옵션으로 붙였을 때의 화면 순서만 확인하는 용도예요. 디자인·문구는 확정이 아니에요.

  1. 기존 환전 흐름은 한 화면도 바꾸지 않아요. 공항 목록에 김포만 추가
  2. 김포로 신청을 마치면 완료 화면에 "발렛도 같이 예약할래요?" 옵션이 하나 붙어요
  3. 안 하면 → 기존처럼 공항에서 직원에게 수령 (끝)
  4. 하면 → 발렛 정보 입력 → 동의 → 수령 방법이 발렛 기사 수령으로 바뀌고 수령권(QR) 발급
  5. 추가 결제 없음: 전달 수수료 2,500원 = 기존 배송료 2,500원

확인할 것
  • 김포에서도 직원 수령을 운영하나요? 발렛을 안 하는 김포 고객은 직원에게 받아야 해서 필요해요. 운영하지 않으면 김포는 발렛 추가가 필수가 돼요.
  • 발렛 추가는 언제까지 가능? (예: 수령 전날까지, 봉투 인계 전)
  • 발렛 차량 인수 장소 (터미널 앞 / 공항 밖) → 수령권 "장소" 문구
  • 기사 화면을 이지백 앱 안에 넣을지 / 별도 웹으로 만들지
  • 이지백과 예약 정보를 주고받는 방식 (링크 / API)
