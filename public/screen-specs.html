화면 구성

영역내용
예약 알림기본 ON 거래 알림 · 수령 1시간 전·10분 전 사전 푸시
환율 알림기본 OFF v1.2 · 정책 미확정
혜택·마케팅기본 OFF 광고성 수신 동의 연동
근처 지점 알림기본 OFF v1.2 반경 300~500m · 72h 쿨다운 · 09~21시

Description

  • 예약 알림은 거래 알림이므로 광고 동의와 무관하게 기본 ON
  • 마케팅 알림과 거래 알림을 분리
  • 푸시 비활성 상태에서도 이메일은 발송됨을 명시

Check Point

  • 환율 알림 ↔ 환율 미노출 정책(RATE-02) 충돌 — 정책 정리 후 설계
  • 근처 지점 알림 = 광고성 푸시 표시 의무 법무 확인 선행(미결)
  • 예약 알림(거래 알림)을 끌 수 없게 할지 확인
