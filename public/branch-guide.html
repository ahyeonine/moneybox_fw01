외국인 환전예약 — 지점 운영 현황

예약이 들어와서 수령(거래완료)될 때까지, 지점은 CEMS로 미리 보고 POS로 처리합니다. 이 페이지에서 상태·응답 의미와 화면별 노출 기준을 먼저 확인하세요.

CEMS는 “오늘 누가 오는지”를 보고 시재를 준비하는 화면이고, 실제 정산·수령은 POS에서만 처리합니다.

시재 원칙

  • 예약 접수는 시재와 무관합니다 — 시재가 부족해도 접수됩니다(품절 거절 없음).
  • 수락한 예약은 반드시 이행 — 시재가 부족하면 지점에서 외화를 조달해 제공합니다.
  • 공급 조절은 사전에 통화별 예약 수락 on/off로 합니다.
  • 실제 시재 차감은 거래완료 시점. 미수령 취소·자동취소는 복구할 시재가 없습니다.
  • 외국인 웹 예약 시재와 통합웹(국내) 예약 시재는 합산하지 않고 채널별로 따로 봅니다.

CEMS 가이드 — 예약 확인 · 시재 준비

CEMS는 지점별 어드민입니다. 우리 지점 예약을 확인하고, 필요하면 지점에서 취소합니다. 입금 확인 화면이 아닙니다 (무결제 예약).

매일 아침: 오늘 수령 예약 확인

  1. [환전예약] → [외국인 환전예약관리] 진입 진입하면 자동으로 수령기간 = 오늘, 방문확인만 보기가 적용됩니다. 별도 조작 없이 “오늘 방문 확정 고객”이 바로 보입니다.
  2. 무응답 고객까지 확인 목록 위 토글을 전체보기로 바꾸면 리마인더에 응답하지 않은 예약도 함께 보입니다. 시재는 무응답 건까지 감안해 준비하세요.
  3. 통화별 필요 금액 파악 [통화] 필터로 통화를 골라 [검색] → 거래금액 합계를 보고 시재를 준비합니다. 부족하면 지점에서 조달합니다(예약 이행 원칙).
  4. 다른 날짜 / 전체 보기 [수령기간]을 바꿔 [검색]하거나 [전체 기간]을 눌러 날짜 제한을 풉니다. [초기화]는 다시 “오늘”로 돌아갑니다.
날짜 필터와 응답 토글은 따로 움직입니다 [전체 기간]을 눌러도 응답 토글은 그대로입니다. 미래 예약의 무응답 건까지 보려면 두 가지를 모두 바꾸세요.

예약 상세 · 지점 취소

  1. 목록에서 행 클릭 예약번호, 상태, 예약자명, 생년월일, 이메일, 지점, 수령일자, 통화, 적용환율, 거래금액, 원화금액, 신청일시가 보입니다.
  2. [예약취소] — 상태가 ‘예약’일 때만 표시 누르면 확인 창이나 사유 입력 없이 즉시 취소됩니다.
    • 상태 → 취소, 방문 알림 해제
    • 고객에게 지점 취소 안내 이메일 자동 발송
    • CEMS 목록에는 행이 남고, POS에서는 처리 대상이 아님
지점 취소는 되돌릴 수 없습니다 누르는 즉시 고객에게 이메일이 나갑니다. 고객 요청 또는 지점 사정이 확실할 때만 사용하고, 시재 부족은 취소 사유가 아닙니다(지점 조달 원칙).

본사관리자 (전 지점)

전 지점 예약을 한 화면에서 봅니다. 지점용 화면과 달리 지점 필터 · 지점 컬럼이 있고, 기본값이 전 지점 + 전체 기간 + 전체보기입니다. 상세 모달에서의 [예약취소]는 지점 취소와 동일하게 처리됩니다.

예약 가능 기간 설정 (본사)

고객이 수령 예정일을 오늘부터 언제까지 고를 수 있는지 정합니다. 지점은 변경할 수 없습니다.

방식동작

일수 지정오늘부터 최대 N일 이내만 선택 (1일 이상). 예: 14일 → 2주 이내

[저장] 즉시 고객 사이트의 수령일 선택 범위와 예약조회 변경에 반영됩니다.

CEMS 체크리스트

  • 오픈 전: 오늘 수령 예약을 방문확인 / 전체보기 둘 다 확인했다
  • 통화별 필요 금액을 확인하고 부족분 조달 계획을 세웠다
  • 다음 영업일 예약도 [수령기간]으로 미리 확인했다
  • 지점 취소는 사유가 확실한 건에만 사용했다

POS 가이드 — 예약 고객 응대 · 거래처리

예약 고객이 방문하면 POS 홈의 환전예약에서 예약을 찾아 신분증을 대조하고 거래를 진행합니다.

POS 홈

SELL외화 파실 때
BUY외화 사실 때
MORE더보기
RESERVATION환전예약
ONLINE EXCHANGE온라인환전

예약 고객은 반드시 RESERVATION (환전예약) 타일로 진입합니다. SELL/BUY로 일반 거래를 하면 예약이 ‘완료’로 바뀌지 않고, 수령기한이 지나면 자동취소로 남습니다.

예약 고객 응대 순서

  1. [환전예약] 타일 선택 상단 토글에서 구분을 고릅니다.
    • 국내예약(기본) — 통합웹 국내 고객
    • 해외예약 — 외국인 웹사이트 고객 (영문 이름)
  2. 예약 목록에서 고객 찾기 예약번호 · 예약자명 · 통화/금액 · 수령일 · 상태가 한 줄로 보입니다. 완료 건은 목록에서 빠집니다.
    • 회원 우대 배지 → 수령 시 현장 재량으로 우대 환율 적용
    • 취소 배지 → 거래 진행하지 않음
  3. 거래내용 확인 예약번호, 상태, 예약자명, 통화, 거래금액, 수령일자를 고객과 함께 확인합니다. 적용환율은 “수령일 환율(미고정)”, 원화금액은 “수령일 정산”으로 표시됩니다.
  4. 신분증(여권) 대조 현장에서 육안 확인합니다. 예약 서비스는 사전에 신분증을 받지 않습니다.
    • 예약자명과 방문자 이름이 달라도 진행 가능 (정책상 동일성 요구 없음)
  5. 거래진행 → 거래완료 [확인]을 누르면 기존 거래처리 화면으로 이어집니다. 오늘 지점 환율로 정산하고, 회원 우대 대상이면 현장에서 우대합니다. 완료 시 예약 상태가 완료로 바뀌고 실제 시재가 차감됩니다.

POS 체크리스트

  • RESERVATION(환전예약) 타일로 진입했다
  • 국내/해외 토글을 고객에 맞게 선택했다
  • 상태가 ‘예약’인지 확인했다 (취소 건은 진행 금지)
  • 신분증(여권)을 육안 대조했다
  • 오늘 지점 환율 + 회원 우대 여부를 반영해 정산했다
  • 거래완료 후 상태가 ‘완료’로 바뀐 것을 확인했다

현장에서 자주 생기는 상황과 처리 방법입니다.

예약 조회

고객이 왔는데 POS·CEMS 목록에 없어요.
기본 화면은 오늘 수령 + 방문확인만입니다. ① 응답 토글을 전체보기로 ② 날짜를 전체로 바꿔 보세요. 그래도 없으면 예약번호 끝 4자리로 검색합니다. 고객이 예약을 변경했다면 예약번호가 새로 발급되었을 수 있습니다.
수령일이 아닌 날에 왔어요.
수령일 이전 방문이면 날짜 토글을 전체로 바꿔 찾고, 상태가 ‘예약’이면 진행할 수 있습니다. 수령일 자정이 지난 건은 자동취소되어 진행할 수 없으니 새로 예약하거나 일반 거래(BUY/SELL)로 안내합니다.
생년월일이 ‘—’로 나와요.
외국인 웹 예약은 생년월일을 수집하지 않습니다. 수령 시 신분증으로 확인하세요.

정산 · 신분증

웹에서 본 환율과 다르다고 해요.
웹 환율은 참고 시세이며, 예약 시점에 환율을 고정하지 않습니다. 실제 적용 환율은 방문일 지점 환율이라고 안내합니다(웹 예약 화면·예약 내역에도 같은 안내가 있습니다).
예약자 본인이 아닌 사람이 왔어요.
정책상 예약자와 수령자의 동일성을 요구하지 않습니다. 방문자의 신분증을 대조해 진행합니다.
회원 우대는 얼마나 해줘야 하나요?
고정 우대율은 없습니다. 수령 시점의 시세·시재 상황을 보고 현장 재량으로 적용합니다.

취소 · 시재

시재가 부족한데 예약을 취소해도 되나요?
안 됩니다. 수락한 예약은 시재가 부족해도 지점에서 외화를 조달해 이행합니다. 공급 조절은 통화별 예약 수락 on/off로 미리 합니다.
고객이 전화로 취소를 요청했어요.
고객이 예약조회(예약번호+이메일)에서 직접 취소하도록 안내하는 것이 기본입니다. 지점에서 처리해야 하면 CEMS 예약 상세의 [예약취소]를 누르세요 — 즉시 취소되고 고객에게 지점 취소 안내 이메일이 발송됩니다.
노쇼 고객은 다음 예약을 막나요?
막지 않습니다. 노쇼는 안내성으로만 운영하며 신규 예약 차단은 없습니다.
무인환전기(머니24h)에서도 예약 수령이 되나요?
아니요. 무인환전기는 지도에 위치 안내용으로만 표시되며, 예약·수령은 유인지점에서만 진행됩니다.
